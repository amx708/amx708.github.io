一句话结论
要约收购套利本质是事件驱动（巴菲特称 Workouts），赚"要约价 − 市场价"的确定性差价，不是您体系里"有可验证现金流"的长期资产。本库以 17 个深研案例（成功/确定 10 + 失败/遇冷 7）为主表，并附扩展速览（早年私有化全面要约经典 + 2024-2026 其余已检索案例），力求覆盖全面要约、部分要约、国资、民营、敌意、竞争性、履行义务型、私有化退市等全部要约类型。规律很清楚：价差大 ≠ 能赚，成败看「类型 + 要约比例 + 收购人履约力 + 标的退市风险」四件套。

扩展表案例多为"公告后股价已推升至要约价附近或之上"，留给二级市场的便宜价差少，故未进主表深研；早年私有化案例是"全面要约无风险套利"范本，值得长期记。完整穷尽 A 股历年全部要约收购（累计数以百计）超出本次检索范围，本库定位为类型全覆盖的代表性样本库。
核心规律：① 部分要约比例越小（汇通 5%、ST龙元 6%），越可能被"只收一小部分、余股补跌"吃掉利润；② 股价远高于要约价时（上纬、天普），要约是"履行法定义务"，接受反而亏；③ 生效条件未达成（金帝石油）、隐瞒一致行动人（汇能海投）、协议价倒挂（君亭）都会让要约直接流产；④ ST标的最好一票否决。

二、静态价差可视化（正=有套利空间，负=履行义务无套利）

鲁阳、奥马的"参与套利绝对收益率"为公开个人实盘记录；汇通为复牌后理论空间（受 5% 比例限制难兑现）；上纬、天普价差为"负"即市价远高于要约价，无套利。横向看：真正有正价差的只有鲁阳/奥马/浙民投/伊泰B等少数案例。

三、巴菲特 / 格雷厄姆套利框架（底层逻辑）

Workouts（套利类）三原则（巴菲特合伙基金时期）：
① 只做公告驱动：不听传闻、不靠内幕，白纸黑字读到才出手；
② 风险是"事件风险"而非"市场风险"：主要亏在"宣布的事件没发生"（反垄断、融资故障、股东反对、监管否决、隐瞒一致行动人）；
③ 套利是闲置资金的高效替代：定位为短期现金等价物，不是核心持仓——"冷却我们放松长期标准的诱惑"。
评估四问（1988 致股东信）落到 A 股要约套利怎么用
① 已宣布的事件确实发生的概率？看生效条件（最低预受门槛）、收购人履约保证金、监管/审批进度、是否 ST/退市
② 资金会被占用多久？要约期 30~60 天 + 清算 3~5 天；占用期决定年化，越长越稀释收益
③ 出现更好结果的概率？保壳成功/资产注入/控股权溢价 → 超额收益期权（如浙民投 3 年 11 亿）
④ 事件未能发生会怎样？要约失败余股退回 + 锚定丧失补跌；ST 标的还可能退市归零

五、要约收购套利前检查清单（10 项 · 每次对照打勾）

  • 要约类型确认：全面要约（股价＜要约价可近似无风险）vs 部分要约（按比例，有补跌）。先定性再算账。
  • 静态价差 ≥ 5% 且覆盖摩擦：价差 =（要约价−市价）/市价；须 > 印花税+佣金+资金占用机会成本，否则白干。
  • 要约比例：≥20% 较安全；<10%（ST龙元 6%、汇通 5%）警惕"只能卖出一小部分、余股补跌"。
  • 生效 / 失效条件：是否有最低预受门槛（金帝石油需 8%）？未达则自始不生效、白忙。
  • 收购人实力与诚意：20% 履约保证金已交？真金白银冻结合约账户？背景是国资 / 产业资本 / 纯 SPV 壳？
  • 预受进度与市场博弈：预受极低 + 股价贴着要约价 = 市场不买账（ST龙元仅 0.04%），危险信号。
  • 标的退市风险：ST / 面值 / 财务 / 规范 / 重大违法——要约期内及结束后都要查，退市即归零。
  • 交易终止风险：协议转让价倒挂（君亭）、监管审批未过、隐瞒一致行动人（汇能海投）、竞争性要约变局。
  • 时间窗口：要约期 30~60 天，最后 3 个交易日不可撤销；算清资金占用天数与年化收益。
  • 退出纪律：未被收购的剩余股份，复牌当日卖出防补跌（科林电气教训）；设硬止损（如破要约价/破面值即撤）。

七、与您的价值投资纪律边界对照

维度要约套利您的价值纪律冲突 / 适配
资产性质事件驱动、短期（30~60 天）长期持有有可验证现金流的资产套利是"现金增强"而非"投资"，不进主仓
收益来源事件确定性差价企业内在价值增长 + 分红不同逻辑；套利赚的是"别人的确定性"
风险类型事件风险（失败/终止/退市）估值 / 基本面 / 系统性套利与大盘弱相关（巴菲特验证），但不能替代基本面研究
仓位卫星仓 / 试错仓主仓质量价值套利仓 ≤ 小比例，硬止损
持有期以"天"计以"年"计套利是闲置资金替代，机会成本对标短债利率
适配建议（个人观点）：把要约套利当成您体系里的"现金管理增强工具"——只在「全面要约+股价低于要约价+标的无退市风险」或「部分要约+比例≥20%+价差厚+收购人强」时，用极小卫星仓参与；ST / 退市边缘 / 比例＜10% / 股价远高于要约价的履行义务型，原则上一票否决（ST龙元、汇通、上纬、天普均属此列）。
