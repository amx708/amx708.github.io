周期脉络：十年一图
🔄 一句话：成品油销售 的「周期」是供需 + 政策 + 地缘的叠加

成品油销售的「周期」是油价传导 + 需求强度 + 新能源替代的叠加，盈利稳定性强但成长性受限。

年份主线事件对行业影响
2015需求平稳成品油表观消费温和增长，销售环节价差稳定。
2016价改推进成品油定价机制完善，炼销价差透明化。
2017竞争加剧地炼资源涌入，终端加油站竞争白热化。
2018民营入局民营加油站与外资加速布局，单站盈利承压。
2019新能源萌芽电动车渗透率起步，长期替代预期升温。
2020需求塌陷疫情出行受限，成品油销量骤降，库存跌价。
2021强劲反弹出行恢复 + 油价上行，销售毛利修复。
2022高位承压高油价抑制需求，新能源替代加速。
2023达峰讨论成品油需求逼近平台期，「达峰」成为行业核心议题。
2024转型提速充电桩 / 综合能源站成为主线，销售企业加速非油业务。
2025存量博弈需求见顶 + 新能源替代，销售环节转向「存量精耕 + 综合能源」。
关键指标与周期信号
信号①

油价传导

销售环节赚「进销价差」，油价急涨时库存收益、急跌时库存损失，温和波动最稳。

信号②

需求达峰

成品油表观需求临近平台期，销量增长逻辑弱化，估值更看分红与资产质量。

信号③

新能源替代

电动车 / 氢能替代是长期结构性压力，销售企业向充电 / 综合能源转型。

信号④

非油业务

便利店 / 充电 / 汽服等非油毛利，是销售环节对抗周期的新增长点。

周期位置是买点判断的「地图」而非「导航」：框架告诉你行业在周期哪一段，但拐点何时出现需结合实时供需与政策验证。结合 估值回测 与 横向对比 综合决策，不构成投资建议。
