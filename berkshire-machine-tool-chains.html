人话版：这个框架怎么用
💡 一句话：机床看的是「五轴国产替代率 + 设备更新给不给订单 + 高端部件卡不卡脖子」

投资机床产业链的关键是看清「周期位置 + 护城河 + 估值锚」：从上游到下游，每一层都有可跟踪的硬指标。

5 层框架其实是回答三个问题：

  • 上游：功能部件谁卡？ 数控系统（华中数控）、丝杠、主轴仍部分进口，是高端机床瓶颈；上游突破决定整机自主度与精度。
  • 中游：做什么机床？ 五轴联动（科德）、立加（纽威、国盛）、龙门（海天）、3C 钻攻（创世纪）；五轴是国产替代制高点。
  • 下游：订单从哪来？ 航空 / 航天 / 军工 / 汽车 / 模具 / 3C 加工需求，设备更新与自主可控直接拉动高端订单。
  • 需求：长期钱在哪？ 「工业母机」自主可控是 10 年级长坡，五轴从进口为主向国产突破是核心增量。
  • 投资逻辑：安全边际在哪？ 机床买点多在「五轴放量 + 估值回调」，高壁垒（科德、华中）更稀缺；但顺制造 capex、周期波动。

实战信号：设备更新 + 五轴突破 → 科德 / 海天 / 创世纪受益；制造业 capex 下行 → 订单放缓。当前估值分化，安全边际来自技术壁垒与替代兑现。

产业周期判断标准
🔄 机床产业链产业链 产业周期怎么看

驱动变量：驱动变量：制造业 capex（设备更新）、五轴国产化率（技术突破）、航空航天 / 军工需求、功能部件自主度。这是「capex—技术—需求」成长周期，顺制造景气。这是「政策—成本—需求」三段式周期，而非传统产能周期。

  • 制造业capex：设备更新 → 机床订单增；下行 → 订单放缓。
  • 五轴替代：技术突破 → 份额跃升；卡验证 → 放量慢。
  • 军工/航天需求：自主可控订单 → 高端放量；波动 → 收入摆动。
  • 功能部件：国产化 → 成本降；进口依赖 → 交付受限。

举例说明：2023–2025 工业母机政策 + 五轴突破（科德、华中），航空航天 / 军工拉动高端订单；2018–2019 制造业下行则通用机床订单疲软。

当前位置（定性框架，非数据结论）：当前位置（定性框架，非数据结论）：机床处「五轴替代 + 设备更新 early-mid + 估值分化」期，自主可控加速、高端放量；变量是制造业 capex 与功能部件突破，安全边际来自技术壁垒。

产业链成本传导

本产业链的成本传导链为：功能部件 → 机床整机 → 加工需求 → 国产替代率。机床产业链没有交易所统一期货（无统一定价期货），成本传导以定性框架 + 周期呈现。

机床无统一期货，成本传导以「功能部件 → 整机 → 加工需求 → 国产替代率」定性框架呈现：上游数控系统突破 → 整机自主度与成本改善。

向上游看：数控系统 / 丝杠 / 主轴仍部分进口，是高端瓶颈；华中数控等突破是关键。

向中游看：五轴（科德）是国产替代制高点，平台化（海天、创世纪）平滑周期；估值分位见上，反映「估值分化」。
