本页把 生猪养殖 / 禽养殖 / 饲料 / 种业 / 动保5 条子链按「上中下游 + 周期」统一框架梳理，便于从投资视角理解农牧产业链的周期位置 + 估值锚 + 成本传导三大核心问题。

周期股框架:农林牧渔是典型的强周期板块,PE 在周期低点会因利润压缩而失真,看 PB 分位才是估值锚——本分类下 PB 分位中位数仅 7%、41/50 家 PB 分位 < 40%,意味着几乎全板块处于历史低估区。
研究信号
周期位置
多链筑底(生猪产能去化中、禽链价格底部、动保刚需稳健)
景气方向
PB 历史底部(中位数 7%)但 PE 失真(中位数 55%,因周期低点利润压缩)
结论信号
🟢 中性偏左侧(布局但不追高) — PB 锚定估值,等景气拐点(猪价/禽价反弹)确认再加
核心催化
①猪价/禽价反弹 ②产能去化兑现 ③种业振兴政策落地 ④动保新品放量
关键风险
①非洲猪瘟/禽流感 ②饲料原料价格(玉米/豆粕) ③政策落地节奏 ④消费需求弱
数据锚:PB 分位中位数 7% · 41/50 家 PB 分位 < 40%(全板块低估) · PE 分位中位数 55%(失真,需 PB 锚替代)。结论为框架合成,需结合实盘研究校验。
跨层分析框架(5 层 · 农牧专属)
01
原料端
玉米/豆粕/鱼粉/添加剂 — 大宗原料,价格波动直接传导下游。
02
种源 + 动保
种猪/种禽/杂交种子 + 兽药/疫苗 — 生物资产与技术密集环节。
03
饲料加工
配方/预混料/浓缩料 — 配方壁垒与渠道下沉,海大集团式范式。
04
养殖生产
生猪/家禽 — 强周期中游,产能利用率与 PSY(母猪年产仔数)为关键。
05
终端与周期
屠宰/肉价/消费/政策 — 价格周期 + 猪粮比 + 政策窗口三重共振。

产业链成本传导

传导方向:原料价格(玉米/豆粕)→ 饲料成本 → 养殖盈亏平衡点 → 终端肉价 → 反向调节上游产能。

关键指标:①猪粮比(猪价/玉米价格,6:1 为盈亏平衡线)鸡料比(鸡价/饲料价格);②能繁母猪存栏(领先猪价 10–12 个月);③玉米/豆粕期货价格(直接关联饲料成本)。

周期逻辑:产能去化 → 供给收缩 → 价格上涨 → 利润修复 → 产能扩张 → 供给过剩 → 价格回落(典型 3–4 年一轮)。左侧布局看产能去化是否兑现、右侧确认看价格反弹是否持续。

期货可观测:玉米、豆粕、豆油(大商所)→ 原料端定价可跟踪;生猪/鸡蛋(大商所)→ 终端定价可跟踪。种业/动保无直接期货,以公司财报与季度批签发数据跟踪。
