一、买点框架：化药的估值锚与白酒有什么不同
🧭 化药的特殊性——盈利稳定但被集采压制
化学制药估值介于白酒（先款后货、定价权强）和创新药（业绩波动大、PE 失真）之间：
1）盈利稳定：10 家公司都有持续归母净利润，PE 口径稳定（不像 biotech 长期亏损），PE / PB 分位有意义；
2）集采压制估值：2018-2024 八批集采把仿制药价格砍 50-90%，化药板块估值中枢系统性下移，不能用绝对 PE 横向比，要用10 年分位 + 历史分位；
3）股息率反而是亮点：化药整体派息率高（恒瑞 5.93%、丽珠 4.6%、人福 2.7%），头部公司把集采的现金回流分红给股东，股息率比 PE 更硬；
4）创新转型期：恒瑞、华东、复星、科伦、人福、信立泰等都在转型创新药，「化药 + 创新」双重估值，仿制药 PE 锚 + 创新药管线进度叠加，买入点要看转型节奏。
⚠️ 数据透明度声明：当前 PE/PB/股息率/ROE 来自本地缓存（_chain_fin_data.json，2025-12-31 截面）；2 家月度收盘价来自 _chain_price_data.json，未做复权调整。回报倍数为近似口径（不扣费用、不计分红再投）。历史底部 PE/股息率精确值未展示——本缓存无 TTM EPS 历史。

📊 底部买入的回报特征
共性规律：底部往往是「PE 极低 + 股息率高 + 创新转型叙事反转」三者共振——但与白酒不同，医药的反转需要更长时间（集采是一次性负向冲击，但人口老龄化、医保腾笼换鸟是长变量）。
2014 底 → 2021 顶：A 股医药黄金十年的主升段，头部标的普遍 3-12×；
2018 底 → 2021 顶：4+7 集采扩面预期的情绪冲击后的修复，科创板 + 医保落地驱动估值回升；
2024 底 → 当前（2026-07）：集采出清 + 创新转型 + 出海 BD 三因子共同作用，绝对收益小于前两轮，反映板块 beta 系统性收缩。
回测 ≠ 预测：历史回报为近似口径（不扣费用、不计分红再投），本轮（2024-25）回报待验证；用估值找「价格安全边际」、用创新管线/政策催化找「时机」，分开看。
五、回测结论：买点信号框架（化学制药特化版）
PE < 20 倍
第一道门 · 集采悲观锚
化药头部 PE 跌破 20 倍通常意味着集采全面悲观已经计入。丽珠 14×、华东 14.3×、人福 15.2×、复星 17.8× 都已落入此区。
股息率 3%+
第二道门 · 最硬的锚
化药整体派息率高：恒瑞 5.93%（化药历史峰值区间）、丽珠 4.6%、科伦 3.0%。股息率不依赖盈利预测，比 PE 更可靠。
创新转型兑现
催化剂确认
低估值是必要条件，化药反转需要看创新药管线进度 + 出海 BD + 集采出清节奏。恒瑞 BD（DLL3 海外授权）+ 科伦博泰港股上市 都是典型催化。
六、当前位置（2026-07）：谁已接近历史极值
📍 本轮（2024-25）与 2014、2018 的对比
已接近历史极值的（PE ≤ 20 倍 + 股息率 ≥ 3%）：
· 丽珠集团 000513：PE 14.0× / PB 1.9× / DY 4.6% / ROE 14.6%——四指标共振，是本组中安全边际最强的标的，但需注意 2025 员工口径调整（见 employee 数据底表）影响 ROE 可比性；
· 华东医药 000963：PE 14.3× / PB 1.9× / ROE 14.3%——医美 + 创新双业务转型已初步兑现；
· 人福医药 600079：PE 15.2× / PB 1.5× / DY 2.7%——PB 极低、麻醉药主业稳定；
· 复星医药 600196：PE 17.8× / PB 1.3×——PB 极低，但 ROE 仅 7.0%、国际化整合负担需消化；
· 恒瑞医药 600276：PE 看似 48.0× 偏高，但 DY 5.93% 接近化药历史极值（2014 化药历史股息率约 5-7%），说明「绝对 PE 高 ≠ 估值高」——市场对持续性折价，需看集采是否进一步压制；

需小心的「估值陷阱」：
· 华海药业 600521：PE 68.4× 但 ROE 仅 2.9%，PE 失真（净利低 + 海外制剂概念推高股价）；
· 信立泰 002294：PE 56.2× / ROE 7.4%，转型期仿制 + 创新双业务并存，估值溢价无法验证；
· 科伦 002422：当前 PE 41.8× / 分位 84%，2024 涨 1.9× 已透支基本面，需等回调；
· 普洛药业 000739：PE 26.1× / ROE 13.6%，CDMO 题材支撑但属主题驱动；

本轮的特殊之处：与白酒「PE 极低 + 高股息率」共振不同，化药 2024-25 底部的特征是「PE 已经低，但市场不相信持续性」——恒瑞 DY 5.93% 创纪录正是这个逻辑的体现。化药的买点不再是「估值杀到位」，而是「市场重新相信持续性」（集采出清 + 创新药放量 + BD 兑现）的事件驱动。
⚠️ 价值陷阱：便宜不等于立即反转
1）持续性折价：化药板块即使 PE 14 倍，市场仍然担心「集采再砍一刀」——这是 2014 / 2018 底都没见过的估值结构；
2）创新转型没兑现：恒瑞、华东、复星、人福、信立泰等转型故事，如果管线 III 期失败，会二次杀估值；
3）股息率 ≈ 自由现金流率：分红率连续多年 >100% 不可持续，需看 OPCF/分红覆盖率；
4）回测 ≠ 预测：历史回报基于已发生的 2014/2018 买点，本轮(2024-25)后续回报待验证。
结论：用 PE + 股息率找「价格的安全边际」，用 集采出清节奏 + 创新药管线 + BD 兑现 找「反转的时机」，两者分开看。
