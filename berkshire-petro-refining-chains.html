炼化板块（炼油 + 石化）是石油石化产业链的「加工端」，承上启下 —— 上受原油成本压制，下受成品油 / 化工品价格影响。A 股炼化民营四巨头（荣盛/恒力/盛虹/桐昆）+ 国资老厂（上海石化/华锦）+ 特色路线（卫星化学 PDH / 宝丰能源煤制烯烃）构成多层次格局。炼化标的估值波动较大（PE 10-70），反映其强周期属性。
研究主题（炼化（炼油+石化））

民营 vs 国资的效率差异

民营四巨头（荣盛/恒力/桐昆/盛虹）ROE 中位 ~7%，国资炼厂（中石化上海/华锦）ROE 中位 ~-2%。差距源于决策效率 + 一体化深度 + 人工成本。化工周期下行期，民营韧性更强。

PX-PTA-聚酯一体化：景气高度相关

PTA 单环节毛利率 2-5%，一体化项目（如荣盛浙石化）从原油到涤纶吃全链毛利 15%+。当纺服需求 + 涤纶价差上行时，一体化标的弹性放大 2-3 倍。

成品油定价机制的「地板红利」

国内成品油40 美元 / 桶地板价机制下，国际油价跌破 40 美元时国内汽柴油不降价，炼厂享受超额毛利；但 130 美元 / 桶天花板价下利润被强制压缩。所以国际低油价是炼化标的的最佳环境。

煤制烯烃的工艺红利

宝丰能源煤制烯烃路线在低煤价（500 元 / 吨以下）时 ROE 可达 25%+，但煤价 800+ 元 / 吨时 ROE 可能跌至 10% 以下。要动态评估煤价 - 油价差，不是简单「煤便宜就好」。

碳中和约束下的产能天花板

中国炼化总产能 2025 年已达9.5 亿吨 / 年，超过国内需求 7 亿吨 / 年。新建炼厂审批已收紧，龙头存量价值正在抬升。但短期内产能过剩仍压制吨毛利。

跨层五维分析

1. 一体化深度：从原油到化纤的链条

民营四巨头（荣盛 / 恒力 / 桐昆 / 盛虹）的核心优势是纵向一体化：原油 → PX → PTA → 聚酯 → 涤纶长丝 / 织造。每个环节多吃一份毛利，对冲单环节景气下行。一体化项目（浙石化 / 大连恒力）规模效应使吨成本低 10-15%。

2. 炼化工艺路线分化

传统炼化（FCC 催化裂化）vs 加氢裂化 vs 煤制烯烃 vs PDH（乙烷脱氢）vs MTO（甲醇制烯烃），不同工艺对原油 / 石脑油 / 煤 / 乙烷的依赖度完全不同。卫星化学 PDH 路线完全规避原油波动，2025 年 ROE 16.8% 全行业最高；宝丰能源煤制烯烃在低煤价时 ROE 24.84% 也是工艺红利。

3. 聚酯产业链的传导周期

PTA - 聚酯 - 涤纶 - 织造周期跟随纺服需求，一般滞后宏观需求 6-12 个月。2024-2025 年纺服出口承压，桐昆 / 恒逸 ROE 仅 5% 左右。当织造库存周期触底回升时，PTA-聚酯环节先受益，弹性最大。

4. 成品油定价机制的红利与约束

国内成品油10 个工作日调整一次，形成「地板价 / 天花板价」机制（40-130 美元 / 桶区间）。地板价下炼厂利润获得保护，天花板价下利润被挤压。上海石化作为典型国资大炼厂，高油价周期利润反不如低油价周期（因为成品油价格滞后传导）。

5. 估值锚与买点

炼化标的的合理估值锚：成熟国资（中石化系）PE 8-12 / PB 0.7-1.0 为合理区间；民营四巨头PE 12-18 / PB 1.5-3.0为合理区间（成长溢价）；特色工艺标的（卫星 / 宝丰）可享有PE 15-25 估值。低于对应区间下沿时往往进入 biddable 窗口。

成本传导：油价 / 煤价 / 石脑油价如何影响本链
原料端： 上游：原油采购（占成本 50-70%），OPEC+ 减产 / 地缘冲突（如红海航运）可短期推升 10-30% 炼化：原油 + 石脑油 + 煤炭 / 天然气（煤制烯烃路线） 零售：批发价（炼厂出厂） + 物流费（短驳 / 长输） 加工端： 折旧（炼厂/管网/加油站投入大）+ 人工 + 能耗（电/蒸汽） 一体化项目（浙石化/恒力）规模效应使吨成本低于行业 10-15% 销售端： 批零差（成品油定价机制：10 个工作日调整一次） 加油站毛利率 5-8%（轻油）+ 非油业务毛利 20%+（便利店/广告） 传导结论： • 油价 ↑ 80 美元/桶时：上游净利 +30%，炼化毛利被挤压（最优炼油价差 5-10 美元/桶） • 油价 ↓ 50 美元/桶时：上游资源价值打折，炼化库存收益 +5-10% • 煤价 ↑ 时：宝丰能源（煤制烯烃）成本压力大；广汇能源煤化工利润同步承压
