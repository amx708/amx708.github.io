🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源电网设备护城河来自技术认证 + 电网客户关系 + 规模制造。二次设备（调度 / 继电保护 / 自动化）壁垒最高（国电南瑞 roe 约 15.7%、四方股份 roe 约 16.9%）；一次设备（变压器 / 开关 / GIS）靠规模与资质（特变电工营收约 972 亿、中国西电 roe 仅 5.5% 分化明显）；出海与储能变压器成新增长极。
2️⃣ 行业集中度与玩家分层行业由国网 / 南网投资主导，呈“二次设备高壁垒寡头（国电南瑞 / 许继 / 四方）vs 一次设备规模竞争（特变 / 西电 / 平高）”格局。思源电气 / 金盘科技凭出海 + 产品力高成长（净利 CAGR 约 24%-35%），长高电新 / 平高电气稳健，中国西电盈利质量偏弱。
3️⃣ 产业链上下游关系上游铜 / 钢 / 绝缘材料 / 芯片 → 一次设备（变压器 / 开关 / GIS）+ 二次设备（继保 / 调度软件）→ 电网工程 EPC → 国网南网。设备厂向电网让渡话语权，高壁垒环节（芯脑软件、出海认证）留存利润。
4️⃣ 周期性与价格话语权弱周期、强政策：投资节奏由新型电力系统建设（特高压 / 配网 / 数智化 / 出海）驱动，订单可见度高；价格话语权向技术壁垒与出海环节集中，低端一次设备价格战压制回报。
5️⃣ 财务质量（盈利/分红/现金流）高质量代表自由现金流转好（思源电气 roe 20.3%、npm 14.6%；国电南瑞 roe 15.7%、npm 12.5%；金盘科技净利 CAGR 约 35%）；规模型一次设备 roe 分化（特变 8%、西电 5.5%）。整体分红稳定、资本开支轻于发电端。
6️⃣ 估值水位与历史分位按订单 + 毛利率 + 出海进度定价：二次设备与出海标的享受成长溢价，一次设备看特高压与配网投资强度、PB 贴近 1-2 倍。历史分位低 + 订单高增时为买点。
7️⃣ 主要风险事件清单电网投资不及预期、特高压 / 配网节奏放缓、原材料（铜钢）涨价、出海贸易壁垒、价格战、应收账款与回款、技术迭代（数智化替代）。
8️⃣ 投资跟踪指标与反向信号跟踪：电网投资完成额、特高压 / 配网招标、二次设备订单、变压器出海量与毛利率、铜价、各公司合同负债与新签订单。

📦 投资逻辑附加：产品定位 / 竞争格局 / 产能周期（占位）

📦 产品定位与投资信号

产品分二次设备（国电南瑞 / 许继电气 / 四方股份：调度、继保、自动化）、一次设备（特变电工 / 中国西电 / 平高电气 / 思源电气：变压器、GIS、开关）、配网与储能（金盘科技 / 长高电新）。投资信号：二次设备壁垒高、出海变压器高成长。

🏛 竞争格局分析

国网南网集采主导，二次设备寡头集中、一次设备规模竞争。本页 10 家覆盖全链，思源电气 / 国电南瑞 / 金盘科技为高质量成长代表，中国西电 / 平高电气偏稳健低估值。

🔄 产能周期与库存周期

产能由电网投资规划驱动，特高压与配网建设节奏决定订单；出海（变压器 / GIS）产能向中国龙头集中。设备扩产周期短于电源，供需随投资脉冲波动，高壁垒环节产能稀缺享溢价。

💬 人话版 · 实战信号

看产业链核心是「周期位置 + 护城河 + 估值锚」三维交叉验证。

  • 先看周期位置：库存/价格/产能/估值 四维判断当前位置。
  • 再看护城河：龙头集中度 + 规模效应 + 准入壁垒。
  • 然后看估值锚：PE/PB 历史分位 + 同行业可比 + 跨市场对比。
  • 警惕陷阱：低估值不等于低估，可能反映景气下行。
  • 实战信号：股息率 + 回购 + 机构持仓 三路验证。

🔄 产业周期判断标准

驱动因素：行业景气由供需结构 + 政策周期 + 货币环境 + 库存周期 共同决定。
