🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源钢铁护城河来自规模成本 + 品种结构。宝钢股份（营收约 3175 亿、净利约 103 亿、roe 约 5%）凭硅钢 / 汽车板技术与宝武协同领先；中信特钢（营收约 1074 亿、roe 约 13.6%、npm 约 5.5%、营收 CAGR 约 33%）凭特钢高壁垒与高附加值稳居盈利质量顶端；南钢股份 roe 约 10.3% 为优质二线。
2️⃣ 行业集中度与玩家分层行业呈“特钢高盈利（中信特钢 roe 13.6%）vs 普钢薄利 / 亏损（华菱 / 首钢 / 太钢 / 杭钢 / 新钢 roe<2%；鞍钢股份 roe -9.3%、净利 -41 亿；钒钛股份 roe -0.8% 亏损）”分化。本页 10 家覆盖特钢到普钢，盈利质量极差极大。
3️⃣ 产业链上下游关系上游铁矿 / 焦炭 → 高炉炼铁 → 炼钢 / 轧材 → 汽车 / 家电 / 地产 / 机械下游。钢厂对铁矿（进口依赖）无定价权，利润被矿价与钢价双向挤压，向具备规模与品种溢价者集中。
4️⃣ 周期性与价格话语权强周期：利润由钢价（供需）+ 铁矿成本（海外寡头定价）剪刀差决定，地产 / 基建需求为总需求锚。价格话语权弱，护城河来自成本与品种而非定价；景气随地产周期大幅摆动。
5️⃣ 财务质量（盈利/分红/现金流）特钢自由现金流转好（中信特钢 roe 13.6%、南钢 roe 10.3%）；普钢薄利且波动大（宝钢 roe 5%、华菱 roe 4.7%），亏损年（鞍钢 -41 亿）吞噬利润。分红随景气波动，特钢更稳定。
6️⃣ 估值水位与历史分位按“PB（重资产，0.6-1 倍为历史底部）+ 吨钢净利 + 矿价钢价价差”定价：特钢看品种溢价与 roe，普钢看周期买点（低 PB + 需求复苏）。历史分位低 + 供给收缩时为逆向布局窗口。
7️⃣ 主要风险事件清单钢价大跌、铁矿 / 焦炭大涨、地产与基建需求坍塌、产能置换与环保限产、出口贸易壁垒、行业产能过剩、资产负债表与债务压力。
8️⃣ 投资跟踪指标与反向信号跟踪：螺纹 / 热卷价格、铁矿与焦炭价格、钢厂吨毛利、地产与基建投资、产量与库存、各公司分化（特钢 vs 普钢）、PB 分位。

📦 投资逻辑附加：产品定位 / 竞争格局 / 产能周期（占位）

📦 产品定位与投资信号

产品分特钢（中信特钢：轴承 / 齿轮 / 工模具钢）、板材（宝钢：汽车板 / 硅钢）、长材（螺纹 / 线材）与不锈钢（太钢）。投资信号：特钢高壁垒优、普钢周期薄利。

🏛 竞争格局分析

宝武（宝钢 / 太钢）龙头集中，中信特钢特钢细分领先；本页 10 家盈利分化：中信特钢 roe13.6% / 宝钢净利103亿 vs 鞍钢 -41亿 / 钒钛亏损。普钢同质化价格战，特钢凭技术溢价。

🔄 产能周期与库存周期

产能受产能置换政策与环保限产约束，供给端强管制；需求随地产基建周期。高炉资产重、退出难，过剩压力下利润薄，景气随供需错配摆动，扩产滞后于需求。

💬 人话版 · 实战信号

看产业链核心是「周期位置 + 护城河 + 估值锚」三维交叉验证。

  • 先看周期位置：库存/价格/产能/估值 四维判断当前位置。
  • 再看护城河：龙头集中度 + 规模效应 + 准入壁垒。
  • 然后看估值锚：PE/PB 历史分位 + 同行业可比 + 跨市场对比。
  • 警惕陷阱：低估值不等于低估，可能反映景气下行。
  • 实战信号：股息率 + 回购 + 机构持仓 三路验证。

🔄 产业周期判断标准

驱动因素：行业景气由供需结构 + 政策周期 + 货币环境 + 库存周期 共同决定。

供需产能利用率/订单饱满度/价格传导
库存主动累库/被动累库/主动去库
价格原料价格/出厂价/终端价
估值PE/PB 历史分位 + 行业相对估值

历史案例：复盘 2018-2020 周期：估值低位 + 业绩拐点 + 产业政策利好 三共振时胜率最高。

当前位置：当前多数子行业估值历史分位偏低，部分龙头股息率创近 5 年新高，景气底部信号渐显。
