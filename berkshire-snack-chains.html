资料说明 这份「休闲食品产业链地图」是怎么来的
本页是借鉴产业链分析方法、用公开资料自行整理的知识框架，把休闲食品上市公司按「层级」拆解，便于从投资视角理解其护城河与渠道变革风险。休闲食品是「可选 + 低粘性 + 渠道驱动」的生意——刚需弱、品牌忠诚低、渠道变革剧烈，不能用白酒/调味品/乳业的尺子量它。
资料来源：各公司年报 / 官网 / 公开新闻 / 行业研报摘要——均为公开事实层；文中数字为近年财报四舍五入值，最新以公司公告为准。

跨层分析框架（5 层）
01
上游原材料
瓜子/坚果/面粉/油脂/糖等农产品 + 包材，价格波动主导成本。
02
中游制造
炒货/烘焙/卤制/膨化，产能利用率与规模效应决定盈利波动。
03
下游渠道
商超/便利/电商/零食量贩，渠道变革剧烈、决定命运。
04
竞争格局
极度分散（无绝对寡头）+ 渠道碎片化，护城河深浅。
05
投资逻辑
周期位置 + 估值锚 + 人效 + 股东回报 四维验证。

产业链成本传导

休闲食品成本传导 相对温和：瓜子/坚果/面粉/油脂/糖等农产品价格有周期，但龙头可通过规模采购 + 配方替代 + 长期合约平抑波动，毛利率波动小于乳业/啤酒。

真正的变量在下游渠道：电商 → 内容电商 → 零食量贩三次渠道革命，每次都重排竞争格局、改写利润率。量贩以「低价 + 高频 + 近场」重构线下，既是盐津/甘源代工的新增长极，也是良品/来伊份传统连锁的降维打击。

龙头（盐津/甘源）凭借 规模制造 + 量贩渠道绑定 兑现人效；中小厂商在渠道变革期被动承压，利润率更不稳定。
