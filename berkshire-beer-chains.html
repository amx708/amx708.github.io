人话版：这个框架怎么用
💡 一句话：啤酒看的是「量稳不稳 + 能不能卖更贵（高端化）+ 成本降不降」

投资啤酒产业链的关键是看清「周期位置 + 护城河 + 估值锚」：从上游到下游，每一层都有可跟踪的硬指标。

5 层框架其实是回答三个问题：

  • 上游：原料谁卡成本？ 大麦依赖进口、麦芽 + 玻璃瓶 / 铝罐是主要成本；近年大麦 / 包材下行直接增厚毛利，是行业性利好。
  • 中游：产能谁出清？ 行业经历产能出清与整合，CR5 高、规模化酿造降本；罐化率提升改善效率与高端承载。
  • 下游：卖给谁？ 餐饮 / 夜场（现饮）溢价高、波动大；流通 / 电商（非现饮）走量；高端大单品靠现饮场景突围。
  • 需求：长期钱在哪？ 总量见顶但结构升级，高端化（U8、乌苏、纯生）是量价齐升主线，社交属性刚性。
  • 投资逻辑：安全边际在哪？ 啤酒买点多在「成本下行 + 高端化兑现 + 低估值高分红」，现金流稳健；强品牌区域壁垒高。

实战信号：大麦 / 包材下行 + 高端放量 → 吨价与毛利双升，关注青岛 / 重庆 / 燕京；餐饮疲软 → 现饮承压、费用投放加剧。当前估值中低位，安全边际来自成本红利与稳定分红。

产业周期判断标准
🔄 啤酒产业链产业链 产业周期怎么看

驱动变量：驱动变量：大麦 / 包材价格（成本）、餐饮景气（现饮需求）、高端化进度（吨价）、产能利用率。这是「成本—需求—结构」三段式周期，弱周期属性。这是「政策—成本—需求」三段式周期，而非传统产能周期。

  • 原料成本：大麦 / 铝罐下行 → 毛利改善；上行 → 成本承压。
  • 餐饮景气：复苏 → 现饮放量、高端提速；疲软 → 现饮承压。
  • 高端化：大单品放量 → 吨价与盈利提升；竞争加剧 → 费用上行。
  • 产能：利用率高 → 摊薄固定成本；过剩 → 折旧拖累。

举例说明：2023–2025 大麦 / 包材下行 + 高端化推进，青岛 / 重庆 / 燕京吨价与盈利改善；2018 包材大涨则成本承压、利润下滑。

当前位置（定性框架，非数据结论）：当前位置（定性框架，非数据结论）：啤酒处「总量见顶 + 高端化中期 + 成本下行」温和向上期，吨价与毛利改善；变量是餐饮复苏与高端竞争，安全边际来自成本红利与高分红。

产业链成本传导

本产业链的成本传导链为：大麦/包材 → 酿造产能 → 渠道投放 → 终端吨价。啤酒产业链没有交易所统一期货（无统一定价期货），成本传导以定性框架 + 周期呈现。

啤酒成本以「大麦（进口）→ 酿造 → 渠道 → 吨价」定性框架呈现：进口大麦与铝罐 / 玻璃下行 → 直接增厚毛利。

向上游看：大麦依赖进口、价格随全球谷物周期；包材（铝罐 / 玻璃）随商品周期，下行期是行业性利好。

向中游看：产能出清后 CR5 高、规模酿造降本，罐化率提升改善效率；估值分位见上，反映「估值中低」。
