人话版：这个框架怎么用
💡 一句话：光模块看的是「AI 算力 capex 有多猛 + 你能不能进大客户供应链 + 估值贵不贵」

投资光模块产业链的关键是看清「周期位置 + 护城河 + 估值锚」：从上游到下游，每一层都有可跟踪的硬指标。

5 层框架其实是回答三个问题：

  • 上游：光芯片谁卡？ EML / 硅光激光器芯片、透镜、连接器是核心，部分高端芯片仍依赖进口；上游突破决定成本与交付。
  • 中游：做什么模块？ 800G 已成主力、1.6T 起步，中际旭创 / 新易盛领跑，天孚（器件）、源杰（芯片）、太辰光（连接器）卡位上游。
  • 下游：订单从哪来？ 海外云厂（ASIC/GPU 集群）以太网重构直接决定需求；单一大客户集中既是机会也是风险。
  • 需求：长期钱在哪？ AI 训练 / 推理集群对高速互连需求爆发，是 10 年级长坡厚雪，800G→1.6T→3.2T 迭代持续。
  • 投资逻辑：安全边际在哪？ 光模块买点多在「订单兑现 + 估值回调」，龙头（旭创、新易盛）与技术领先者更抗波动；但高估值 + 客户集中需控仓。

实战信号：云厂 AI capex 高增 + 800G/1.6T 放量 → 旭创 / 新易盛 / 天孚爆发；capex 不及预期或客户集中风险 → 回撤。当前估值高位，安全边际来自成长兑现。

产业周期判断标准
🔄 光模块产业链产业链 产业周期怎么看

驱动变量：驱动变量：云厂 AI capex（ASIC/GPU 集群）、速率迭代（800G→1.6T）、技术路线（硅光 / LPO）、客户份额。这是「capex—技术—份额」强成长周期。这是「政策—成本—需求」三段式周期，而非传统产能周期。

  • 云厂capex：AI 高增 → 模块需求爆发；放缓 → 订单递延。
  • 速率迭代：800G→1.6T → 单价与份额跃升；掉队 → 出局。
  • 技术路线：硅光 / LPO 胜出 → 卡位者受益；误判 → 沉没。
  • 客户份额：进大客户供应链 → 放量；丢单 → 估值崩。

举例说明：2023–2025 海外云厂 AI capex 暴增，800G 模块（中际旭创、新易盛）收入与利润爆发、1.6T 接力；此前 200G/400G 周期则随云厂 capex 波动。

当前位置（定性框架，非数据结论）：当前位置（定性框架，非数据结论）：光模块处「AI 算力爆发 + 估值历史高位」强成长期，800G/1.6T 放量、龙头领跑；变量是云厂 capex 与客户集中，安全边际来自成长兑现而非低估值。

产业链成本传导

本产业链的成本传导链为：光芯片/器件 → 模块制造 → 云/AI算力 → 速率迭代。光模块产业链没有交易所统一期货（无统一定价期货），成本传导以定性框架 + 周期呈现。

光模块无统一期货，成本传导以「光芯片 → 模块 → 云算力 → 速率迭代」定性框架呈现：上游光芯片突破 → 模块成本与交付改善。

向上游看：EML / 硅光激光器芯片仍部分进口，是高端模块瓶颈；源杰（芯片）、天孚（器件）卡位上游。

向中游看：速率迭代（800G→1.6T）抬升单价与份额，龙头（旭创、新易盛）领跑；估值分位见上，反映「估值高位」。
