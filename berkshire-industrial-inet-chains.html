🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源工业互联护城河分两类：制造端规模（工业富联营收约 9029 亿、净利约 353 亿、gpm 7%、roe 21.2% 全球电子代工龙头，客户 + 规模壁垒）与软件 / 平台端绑定（宝信软件营收约 110 亿、roe 11.8%、npm 11.9% 钢铁信息化深度绑定；中控技术流程工业软件）。能科科技（gpm 49%、npm 14.8%）凭工业软件实施高盈利。
2️⃣ 行业集中度与玩家分层行业呈“代工龙头（工业富联）vs 行业软件（宝信 / 中控 / 用友 / 鼎捷）vs 亏损转型（用友网络净利 -14 亿、roe -18.3% 云转型投入期；东方国信 -2 亿；赛意 -1 亿）”分化。本页 10 家覆盖设备 + 软件 + 平台，盈利质量参差。
3️⃣ 产业链上下游关系上游设备 / 云 / 数据 → 工业软件（MES / ERP / PLC 软件）+ 工业互联网平台 → 制造企业与产线。软件端对客绑定强、续费稳；代工端规模与客户锁定；价格话语权向平台与头部代工集中。
4️⃣ 周期性与价格话语权弱周期、顺数字化：需求随制造业数字化与 AI + 工业融合稳步增长；代工受消费电子 / AI 服务器周期影响，软件受企业 IT 开支影响。价格话语权向头部平台集中，同质化软件价格战。
5️⃣ 财务质量（盈利/分红/现金流）代工龙头自由现金流厚（工业富联 roe 21.2%、净利 353 亿）；行业软件分化（宝信稳健、能科高盈利、用友深亏转型）。软件标的分红弱、研发 / 销售开支大。
6️⃣ 估值水位与历史分位按“绑定深度 + roe + AI 工业落地”定价：代工看规模与 AI 服务器弹性，软件看产品化率与续费；历史分位低 + 数字化政策时为买点，规避深亏转型标的。
7️⃣ 主要风险事件清单制造业 IT 开支下滑、消费电子 / AI 服务器周期下行、云转型持续亏损、价格战、应收账款与回款、技术迭代、客户集中度高、贸易壁垒（代工出海）。
8️⃣ 投资跟踪指标与反向信号跟踪：制造业数字化投资、AI 服务器出货、工业软件订阅化率、各公司毛利率与经营现金流、宝信 / 中控订单、用友扭亏进度、股息率。

📦 投资逻辑附加：产品定位 / 竞争格局 / 产能周期（占位）

📦 产品定位与投资信号

产品分电子代工（工业富联：服务器 / 通信设备）、工业软件（宝信 / 用友 / 鼎捷 / 汉得：MES/ERP）、工业互联网平台（东方国信 / 赛意 / 能科）。投资信号：代工规模 + 行业绑定软件优，深亏转型需规避。

🏛 竞争格局分析

代工端工业富联全球领先；软件端宝信（钢铁）、中控（流程）行业壁垒高，用友通用 ERP 承压。本页 10 家分化：工业富联净利353亿 / 宝信 roe11.8% vs 用友 -14亿。客户绑定与产品化率是核心。

🔄 产能周期与库存周期

代工产能随 AI 服务器需求全球布局，软件产能弹性大（人力驱动）；供给端代工重资产、软件轻资产。数字化与 AI 工业融合打开增量，产能随需求平稳扩张。

💬 人话版 · 实战信号

看产业链核心是「周期位置 + 护城河 + 估值锚」三维交叉验证。

  • 先看周期位置：库存/价格/产能/估值 四维判断当前位置。
  • 再看护城河：龙头集中度 + 规模效应 + 准入壁垒。
  • 然后看估值锚：PE/PB 历史分位 + 同行业可比 + 跨市场对比。
  • 警惕陷阱：低估值不等于低估，可能反映景气下行。
  • 实战信号：股息率 + 回购 + 机构持仓 三路验证。

🔄 产业周期判断标准

驱动因素：行业景气由供需结构 + 政策周期 + 货币环境 + 库存周期 共同决定。

供需产能利用率/订单饱满度/价格传导
库存主动累库/被动累库/主动去库
价格原料价格/出厂价/终端价
估值PE/PB 历史分位 + 行业相对估值

历史案例：复盘 2018-2020 周期：估值低位 + 业绩拐点 + 产业政策利好 三共振时胜率最高。

当前位置：当前多数子行业估值历史分位偏低，部分龙头股息率创近 5 年新高，景气底部信号渐显。
