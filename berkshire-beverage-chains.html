资料说明 这份「软饮料产业链地图」是怎么来的
本页是借鉴产业链分析方法、用公开资料自行整理的知识框架，把软饮料上市公司按「层级」拆解，便于从投资视角理解其护城河与渠道风险。软饮料是「刚需 + 高频 + 品牌驱动」的生意——比休闲食品粘性更高、比白酒/调味品规模效应更弱，但渠道与品牌壁垒显著。功能饮料（东鹏）处于高景气，传统植物蛋白/冲泡（养元/香飘飘）增长见顶。
资料来源：各公司年报 / 官网 / 公开新闻 / 行业研报摘要——均为公开事实层；文中数字为近年财报四舍五入值，最新以公司公告为准。
研究信号
周期位置
消费筑底、软饮料需求稳健（刚需 + 高频），但增长分化明显（功能饮料强、传统乳饮弱）
景气方向
功能饮料（东鹏）高景气、包装水稳健；植物蛋白（养元）/ 冲泡（香飘飘）见顶，行业中位偏低（PE分位≈36% / PB分位≈27%）
结论信号
🟡 中性偏左侧（精选个股，不追指数） — 多数估值分位偏低，但个股分化大：龙头（东鹏）与困境（均瑶/珠海中富）并存，须自下而上挑
核心催化
①消费复苏预期 ②渠道下沉与即饮场景 ③新品（无糖茶 / 功能饮料）放量 ④股东回报（分红/回购）
关键风险
①需求持续疲弱 ②原料（糖/PET/浓缩汁）价格波动 ③渠道库存 ④价格战 ⑤食品安全
数据锚：PE分位≈36% PB分位≈27%（中位偏低） · 东鹏ROE 51.6% 顶级 / 承德露露18.1% / 养元13.2% · 养元PB 4.67 95%极贵 / 珠海中富PB 33.41 96%极贵且ROE -69% 巨亏三重警示。结论为框架合成，需结合实盘研究校验。

产业链成本传导

软饮料成本传导 受原料价格周期影响明显：糖、PET 瓶坯、浓缩果汁等价格有周期，但龙头可通过规模采购 + 长协锁价 + 配方优化平抑波动，毛利率波动小于包装成本敏感型上游。

真正的变量在下游渠道：传统经销 → 现代商超 → 电商/即饮三次渠道演进，每次都重排竞争格局。功能饮料（东鹏）靠「大单品 + 下沉渠道 + 高频复购」兑现人效；传统冲泡（香飘飘）受即饮化冲击增长见顶。

珠海中富 这类 PET 瓶坯/包装供应商处于产业链最上游，盈利随下游饮料资本开支与 PET 价格剧烈波动，与品牌商不可直接横比。
