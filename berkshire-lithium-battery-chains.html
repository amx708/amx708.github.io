人话版：这个框架怎么用
💡 一句话：锂电池看的是「锂价降没降（成本）+ 你的份额涨没涨 + 储能给不给增量」

投资锂电池产业链的关键是看清「周期位置 + 护城河 + 估值锚」：从上游到下游，每一层都有可跟踪的硬指标。

5 层框架其实是回答三个问题：

  • 上游：锂谁定价？ 锂矿 / 盐湖随全球供给周期剧烈波动，2023 后暴跌至底部，直接改善电芯毛利；资源自给率高的（赣锋、天齐，此处宁德 / 国轩布局）平滑成本。
  • 中游：做什么电芯？ 动力（宁德、比亚迪、亿纬、国轩）、储能（鹏辉、派能）、消费（欣旺达、德赛）；宁德全球份额领先、比亚迪垂直一体化。
  • 下游：卖给谁？ 新能源车（国内稳健 + 出海）、储能（海内外爆发）、消费电子（复苏）；车 + 储双轮决定需求。
  • 需求：长期钱在哪？ 电动化 + 储能是 10 年级长坡，储能从政策驱动转向平价驱动，增量最确定。
  • 投资逻辑：安全边际在哪？ 锂电买点多在「锂价底部 + 低估值 + 份额领先」，龙头（宁德、比亚迪）更抗过剩；但强周期需控仓。

实战信号：锂价触底 + 储能爆发 → 毛利与量双升（宁德、亿纬、鹏辉）；产能过剩价格战 → 二三线承压。当前估值低位，安全边际来自锂价底部与龙头份额。

产业周期判断标准
🔄 锂电池产业链产业链 产业周期怎么看

驱动变量：驱动变量：锂价（供给周期）、新能源车销量、储能装机、产能过剩度（价格战）、技术迭代（固态）。这是「锂价—需求—产能」强周期。这是「政策—成本—需求」三段式周期，而非传统产能周期。

  • 锂价：触底回升 → 资源端受益、电芯成本稳；再下行 → 电芯毛利承压。
  • 车/储需求：高增 → 量价齐升；放缓 → 价格战。
  • 产能过剩：出清 → 格局改善；过剩 → 毛利压缩。
  • 技术迭代：固态突破 → 卡位者受益；误判 → 沉没。

举例说明：2024–2025 锂价暴跌至底部后企稳、储能爆发，宁德 / 亿纬 / 鹏辉毛利改善、储能放量；2022 锂价暴涨则资源端暴利、电芯承压，2023 锂价崩则资源端反噬。

当前位置（定性框架，非数据结论）：当前位置（定性框架，非数据结论）：锂电处「锂价底部 + 估值历史低位」早中期，储能爆发、龙头集中度提升；变量是产能过剩与锂价走势，安全边际来自锂价底部与龙头份额。

产业链成本传导

本产业链的成本传导链为：锂资源 → 电芯与材料 → 应用终端 → 锂价周期。锂电池产业链没有交易所统一期货（无统一定价期货），成本传导以定性框架 + 周期呈现。

锂电成本以「锂资源（矿/盐湖）→ 电芯与材料 → 应用终端 → 锂价」强周期框架呈现：锂价（全球供给周期）触底 → 电芯成本改善、毛利修复。

向上游看：锂矿 / 盐湖价格波动剧烈，资源自给率高的企业（一体化布局）平滑成本；锂价底部是行业性利好。

向中游看：储能从政策驱动转向平价驱动增量最确定，龙头（宁德、比亚迪）靠份额与一体化抗过剩；估值分位见上，反映「估值低位」。
