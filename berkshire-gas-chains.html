🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源燃气护城河在区域特许经营权（管网自然垄断）+ 稳定接驳用户。城燃商靠“接驳费 + 售气价差 + 增值服务”盈利，毛利率受门站进价与终端售价（政府管制）双向挤压，普遍不高（gpm 约 6%-18%）。全产业链龙头新奥股份（上游气源 + 贸易 + 城燃 + 工程）规模约 1315 亿、roe 约 19% 最优，但贸易拉低净利率至 3.6%。
2️⃣ 行业集中度与玩家分层行业呈“区域城燃（深圳 / 成都 / 重庆 / 贵州 / 陕天然等）割裂经营 vs 全产业链龙头（新奥股份）vs 贸易扩张型（佛燃能源营收 CAGR 约 23%）”格局。盈利质量分化：东方环宇（区域小龙头 gpm 29%、npm 16.2%）最优；贵州燃气 / 重庆燃气微利（roe 1.5% / 3.6%），受价差收窄拖累。
3️⃣ 产业链上下游关系上游气源（国产 + 进口 LNG / 管道）→ 干线 / 城市管网 → 城燃分销 + 接驳 → 工商业 / 居民终端。城燃对进价无控制权、售价受管制，利润取决于购销价差与接驳量，向有气源 / 规模优势的龙头集中。
4️⃣ 周期性与价格话语权弱周期、强管制：需求随经济与气温平稳，售气价差由政策锚定；价格话语权弱，护城河来自特许经营而非定价。贸易型扩张（佛燃）增厚营收但摊薄毛利，景气看气价与顺价机制。
5️⃣ 财务质量（盈利/分红/现金流）整体薄利且重接驳：贸易 / 大用户拉低净利率（新奥 3.6%、佛燃 3.1%）；区域高气价 + 高接驳标的盈利厚（东方环宇 npm 16.2%、成都燃气 npm 9%）。自由现金流受管网资本开支与接驳周期影响，分红中等。
6️⃣ 估值水位与历史分位按“股息率 + 销气增速 + 顺价机制”定价：区域城燃 PB 贴近 1 倍、看股息保护；新奥股份看全产业链协同与贸易量。历史分位低 + 顺价落地时为买点，避免微利高估值标的。
7️⃣ 主要风险事件清单气价大涨且顺价不畅、售气价差收窄、接驳量下滑、LNG 进口波动、管网建设资本开支、安全监管、居民气价倒挂、贸易业务风险。
8️⃣ 投资跟踪指标与反向信号跟踪：天然气进口价与 LNG 现货、门站与终端价差、接驳户数、销气量增速、各公司股息率与自由现金流、顺价政策落地。

📦 产品定位与投资信号

产品分城燃分销（深圳 / 成都 / 重庆 / 贵州 / 陕天然 / 蓝天 / 东方环宇）、全产业链（新奥股份：气源 + 贸易 + 工程）、贸易扩张（佛燃能源）。投资信号：区域特许经营稳、全产业链龙头优、微利城燃需规避。

🏛 竞争格局分析

城燃区域分割、各自为战，新奥股份以全产业链规模领先；本页 10 家盈利分化：东方环宇 npm 16.2% vs 贵州燃气 npm 0.7%。新奥 / 佛燃营收高增但毛利薄，区域龙头靠接驳留存利润。

🔄 产能周期与库存周期

管网为自然垄断资产、建设受特许审批，供给端刚性；销气能力随城市开发与接驳用户增长。贸易型扩张弹性大但利润薄，气源自主（新奥）是核心壁垒，产能随需求平稳释放。

💬 人话版 · 实战信号

看产业链核心是「周期位置 + 护城河 + 估值锚」三维交叉验证。

  • 先看周期位置：库存/价格/产能/估值 四维判断当前位置。
  • 再看护城河：龙头集中度 + 规模效应 + 准入壁垒。
  • 然后看估值锚：PE/PB 历史分位 + 同行业可比 + 跨市场对比。
  • 警惕陷阱：低估值不等于低估，可能反映景气下行。
  • 实战信号：股息率 + 回购 + 机构持仓 三路验证。

🔄 产业周期判断标准

驱动因素：行业景气由供需结构 + 政策周期 + 货币环境 + 库存周期 共同决定。

供需产能利用率/订单饱满度/价格传导

价格原料价格/出厂价/终端价

历史案例：复盘 2018-2020 周期：估值低位 + 业绩拐点 + 产业政策利好 三共振时胜率最高。
