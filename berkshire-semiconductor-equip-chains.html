🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源① 商业模式与护城河来源：半导体设备是技术/资本/客户认证三重壁垒最高的环节。护城河来自工艺Know-how积累（千级工艺配方）、与晶圆厂联合开发形成的认证绑定、以及零部件供应链自主化。北方华创（393亿、10年CAGR 41.5%）平台化最广，中微（CCP/ICP刻蚀+MOCVD）、拓荆（PECVD）、华海清科（CMP）、中科飞测（量测）各踞细分冠军。
2️⃣ 行业集中度与玩家分层② 行业集中度与玩家分层：全球由AMAT/LAM/TEL等美日巨头主导，国内处于快速替代窗口。分层：平台型（北方华创）> 细分冠军（中微/拓荆/华海清科/盛美/中科飞测）> 新兴/转型（微导纳米/芯源微/万业企业）。国产份额仍低，但刻蚀、清洗、CMP、量测等环节突破最快。
3️⃣ 产业链上下游关系③ 产业链上下游关系：上游为精密机械/光学/真空/射频电源/EDA-工艺包，受美日设备与零部件管制约束；下游为晶圆厂（存储/逻辑/代工）资本开支。设备厂营收与下游capex高度同步且前置——下游扩产直接驱动订单，故板块Beta高于材料。
4️⃣ 周期性与价格话语权④ 周期性与价格话语权：强周期（跟随全球半导体capex周期，yoyσ普遍30-140%）。设备厂对晶圆厂议价能力有限、且面临海外巨头与内资同业双重竞争，但细分冠军因稀缺性有一定溢价。华海清科/拓荆等高增长伴随高波动（拓荆yoyσ 67.6%）。
5️⃣ 财务质量（盈利/分红/现金流）⑤ 财务质量：高研发投入致报表净利润偏低、净利率分化（盛美20.6%、华海清科23.3%较高；芯源微3.7%、中科飞测2.9%、精测2.5%偏低）。ROE多处于爬坡期（多数roe中位个位%~15%）。关注研发费用资本化、存货（在制设备）与合同负债（预收款）质量，而非表面净利。
6️⃣ 估值水位与历史分位⑥ 估值水位与历史分位：板块长期享受国产替代溢价，绝对PE偏高且随景气大幅摆动。本页PE横截面仅取回部分报价（部分个股无实时quote）。建议以PS/订单可见度+10年盈利分位综合判断，警惕主题情绪透支。
7️⃣ 主要风险事件清单⑦ 主要风险事件清单：美日设备/零部件出口管制升级；下游晶圆厂capex不及预期或延期；先进制程突破慢于预期、成熟制程价格战；高估值回撤与股东减持；关键零部件（真空泵/射频源/光学）供应链断点。
8️⃣ 投资跟踪指标与反向信号⑧ 投资跟踪指标与反向信号：跟踪——中芯/长存/长鑫等晶圆厂capex指引、设备招标中标份额、合同负债与存货周转、零部件国产化率、HBM/先进封装扩产。反向信号——capex下修、中标份额下滑、存货减值、估值与订单背离。

🏛 竞争格局分析

全球AMAT/LAM/TEL/KLA主导，国产替代处于从0到1到从1到N阶段。刻蚀（中微）、清洗（盛美）、CMP（华海清科）、涂胶显影（芯源微）、量测（中科飞测）已实现突破并获晶圆厂重复订单；但光刻、离子注入、过程控制仍薄弱。内资同业在细分环节直接竞争，价格与份额博弈加剧。

🔄 产能周期与库存周期

产能随订单节拍扩张，设备厂以销定产、存货多为在制设备。当前处于国产替代加速+先进制程/存储扩产共振阶段，但需警惕重复下单与晶圆厂capex节奏波动。跟踪要点：招标批次与单价趋势、产能利用率、零部件交付周期。

人话版：这个框架怎么用
💡 一句话：半导体设备看的是「国产替代率能提到多高 + 晶圆厂敢不敢扩产 + 估值贵不贵」

投资半导体设备产业链的关键是看清「周期位置 + 护城河 + 估值锚」：从上游到下游，每一层都有可跟踪的硬指标。

5 层框架其实是回答三个问题：

  • 上游：零部件谁卡脖子？ 真空 / 射频 / 光学部件、石英 / 陶瓷等仍部分依赖进口，是国产化深层瓶颈；上游突破决定整机自主度。
  • 中游：做什么设备？ 刻蚀（中微）、薄膜沉积（拓荆、微导）、清洗（盛美）、CMP（华海清科）、涂胶显影（芯源微）、量测（精测、中科飞测）、平台型（北方华创）；平台化企业空间更大。
  • 下游：订单从哪来？ 中芯 / 长存 / 长鑫等晶圆厂扩产直接决定设备订单；逆全球化下国产线capex刚性。
  • 需求：长期钱在哪？ 自主可控是 10 年级长坡厚雪，国产化率从低个位数向 30%+ 提升是核心增量。
  • 投资逻辑：安全边际在哪？ 设备买点多在「订单高增兑现 + 估值回调至合理」，平台化与品类扩张者更抗波动；但高估值需时间消化。

实战信号：晶圆厂扩产 + 国产化率提升 → 订单高增（北方华创、中微、拓荆），关注平台化；海外限制升级或 capex 不及预期 → 回撤。当前估值中高，安全边际来自成长兑现而非低估值。

产业周期判断标准
🔄 半导体设备产业链产业链 产业周期怎么看

驱动变量：驱动变量：晶圆厂 capex（扩产节奏）、设备国产化率（政策 + 验证进度）、海外限制（出口管制）、大基金周期。这是「政策—capex—国产化」三段式强成长周期。这是「政策—成本—需求」三段式周期，而非传统产能周期。

  • 晶圆厂capex：扩产 → 设备订单高增；放缓 → 订单递延。
  • 国产化率：验证通过 → 份额跃升；卡验证 → 放量慢。
  • 海外限制：升级 → 倒逼国产替代加速；缓和 → 竞争加剧。
  • 大基金：加码 → 资金与订单共振；退坡 → 估值承压。

举例说明：2023–2025 晶圆厂逆全球化扩产 + 大基金三期，北方华创 / 中微 / 拓荆订单与收入高增、国产化率快速提升；2019 前则国产设备几乎空白、依赖进口。

当前位置（定性框架，非数据结论）：当前位置（定性框架，非数据结论）：半导体设备处「国产替代加速 + 估值中高位」强成长期，订单高增、平台化突破；变量是晶圆厂 capex 与海外限制，安全边际来自成长兑现而非低估值。

产业链成本传导

本产业链的成本传导链为：零部件/材料 → 设备制造 → 晶圆厂扩产 → 国产替代率。半导体设备产业链没有交易所统一期货（无统一定价期货），成本传导以定性框架 + 周期呈现。

半导体设备无统一期货，成本传导以「零部件 → 整机 → 晶圆厂 → 国产化率」定性框架呈现：上游零部件突破 → 整机自主度与毛利提升。

向上游看：真空 / 射频 / 光学等核心零部件仍部分进口，是国产化深层瓶颈，突破后整机成本与交付改善。

向中游看：平台型企业（北方华创）品类扩张平滑单品周期，细分龙头靠验证放量；估值分位见上，反映「估值中高」。
