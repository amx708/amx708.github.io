人话版：这个框架怎么用
💡 一句话：保险看的是「负债成本能不能降 + 投资端能不能赚 + 估值够不够低」

投资保险产业链的关键是看清「周期位置 + 护城河 + 估值锚」：从上游到下游，每一层都有可跟踪的硬指标。

5 层框架其实是回答三个问题：

  • 上游：保单负债成本谁定？ 寿险 / 产险 / 健康险的预定利率与赔付率是核心，负债成本下行（产品定价下调）直接改善利差，是近年最核心变量。
  • 中游：钱投去哪？ 保险资金以固收为主、权益为辅，长端利率与权益市场决定总投资收益；平安等综合金融还有银行 / 资管协同。
  • 下游：保费从哪来？ 个险代理人、银保、经代三条渠道决定新单规模；代理人企稳、银保发力是近年结构改善点。
  • 需求：长期钱在哪？ 老龄化 + 居民储蓄搬家（保本理财向年金 / 增额寿迁移）是慢变量刚需。
  • 投资逻辑：安全边际在哪？ 保险买点多在「估值低位（PEV<1）+ 负债成本下行 + 投资收益修复」，分红稳定；但利率与权益波动要求控仓。

实战信号：长端利率企稳 + 权益回暖 → 投资收益与估值双修复，关注平安 / 太保 / 国寿；利率下行 → 利差收窄、估值承压。当前估值处历史低位，安全边际来自低 PEV 与高股息，而非高成长故事。

产业周期判断标准
🔄 保险产业链产业链 产业周期怎么看

驱动变量：驱动变量：长端利率（10Y 国债，决定固收再投资收益与利差）、权益市场（投资收益弹性）、负债成本（产品预定利率下调）、新单结构（期交 / 价值率）。这是「利率—负债—资产」三段式周期。这是「政策—成本—需求」三段式周期，而非传统产能周期。

  • 长端利率：企稳回升 → 固收再投资收益率改善、利差走阔；下行 → 利差收窄。
  • 权益市场：上行 → 投资收益弹性释放、EV 增厚；下行 → 浮亏拖累。
  • 负债成本：预定利率下调 → 新单利差改善、价值率提升。
  • 新单结构：期交 / 保障型占比提升 → 业务质量改善、NBV 增长。

举例说明：2023–2025 负债成本（预定利率）连续下调、长端利率触底企稳，头部险企（平安、太保）NBV 转正、估值处历史低位；2018–2019 利率下行期则利差收窄、估值承压。

当前位置（定性框架，非数据结论）：当前位置（定性框架，非数据结论）：保险处「负债成本下行 + 估值历史低位」早中期，投资收益随权益回暖修复；变量是长端利率走势与权益波动，安全边际来自低 PEV 与高股息。

产业链成本传导

本产业链的成本传导链为：长端利率 → 负债成本 → 投资收益 → 险企盈利。保险产业链没有交易所统一期货（无统一定价期货），成本传导以定性框架 + 周期呈现。

保险没有统一期货，成本传导以「利率 → 负债成本 → 投资收益 → 利润」定性框架呈现：长端利率企稳 → 固收再投资收益改善、利差走阔。

向上游看：负债端预定利率下调直接压低保单成本，是近年行业性利好；但存量高成本保单仍需时间消化。

向中游看：投资端以固收为主，权益弹性随市场回暖释放；综合金融（平安）还有银行 / 资管协同平滑周期；估值分位见上，反映「估值低位」。
