③ 6 个最该记住的"读法"

  1. 看衰退：10Y-2Y 倒挂是先行信号（领先 6-18 月）；NBER 是事后确认。倒挂出现就要开始防衰退
  2. 看降息预期：CPI 见顶 + 就业弱化 → Fed 降息 → 美债 10Y 跌 → 全球估值压力释放 → A 股 / 港股利好
  3. 看资金流向：美 10Y↑ + 美元↑ → 资金回流美国 → A 股 / 港股承压（北向资金外流）
  4. 看油价：油价高企 → 通胀粘性 → 降息延后 → 高估值股票承压（特别是港股科技 / 成长）
  5. 看汇率：USDCNY 6.5- 外资流入友好；6.8+ 警惕资本外流；7+ 警报
  6. 看 NBER 位置：距上次衰退 >60 月 → 后期阶段，估值要更保守，高 PE 标的需折价

④ A 股传导链（核心）

美国变量传导路径A 股影响
Fed 降息美元↓ → 人民币↑ → 外资流入利好成长股（创业板 / 科创板 / 港股科技）
Fed 降息美债 10Y↓ → 全球估值锚↓利好长久期资产（消费 / 医药 / 科技）
美元走弱大宗商品↑ → 资源股利好有色 / 石油 / 煤炭
衰退发生全球需求↓ → 出口承压利空出口股；利好防御（公用 / 必需消费）
10Y 倒挂 → 衰退风险偏好↓利好红利 / 低估值 / 高股息（银行 / 电力 / 煤炭）
附注：传导链为逻辑示意，实际路径受国内政策、估值水平、市场情绪多重干扰，不可机械套用。本看板仅作外盘背景参考，不构成投资建议。

⑤ 衰退专题：NBER + 10Y-2Y 怎么配合用

  • NBER（事后）：NBER 委员会认定的衰退起止月。权威但滞后（衰退结束半年后才正式认定）
  • 10Y-2Y（先行）：每次倒挂后 6-18 月大概率衰退。1960 年来 8 次倒挂 7 次衰退（领先 6-22 月）
  • 2008 案例：2006-07 利差倒挂 → 2007-12 NBER 衰退开始 → 间隔 17 个月
  • 2020 案例：2019-08 利差倒挂 → 2020-02 NBER 衰退开始 → 间隔 6 个月（COVID 加速）
  • 现在：10Y-2Y 正常 +0.41pp → 衰退信号未亮，但要持续盯（一旦转负就要提高警惕）

⑥ 数据使用纪律

本看板是外盘背景参考，不是 A 股择时信号。
- 7 个指标都滞后或领先，不是即时信号（PMI 当月、CPI 滞后半月）
- 单一指标信号不可靠（Fed 鹰派时也常降息、市场常忽视倒挂）
- 正确用法：看方向（宽松还是紧缩）+ 看位置（扩张前期还是后期）
- 不构成投资建议；A 股投资请结合国内 PMI / 社融 / CPI / 政策

⑦ 人话解读 + 操作建议（按当前数据）

📌 操作总览（防御为主）：红利 / 高股息压舱（>40% 仓位）· 减仓高 PE 港股科技 · 加仓低估值高股息（待回调）· 现金 15-25% 等降息 · 关键转折：CPI <2.5% = 港股科技真机会
美联储利率--
人话：Fed 维持限制性利率（3.6%），打压通胀但也压制经济；降息预期被持续推迟。
操作：高估值成长股（创业板/科创板/港股科技）继续承压；红利 / 高股息（银行 / 电力 / 煤炭）作压舱石。
关注：CPI 3.3% 黏性 → 决定 Fed 何时松手。
美元 / 人民币--
人话：人民币偏弱但未崩，外资进出中性。A 股 / 港股估值受美元流动性间接压制。
操作：港股科技 / 医药 / 消费（外资定价）继续承压；A 股内需股相对受影响小。
关注：USDCNY 7+ 警报线；6.5- 外资可能加速流入。
WTI 原油--
人话：油价中高位，需求强 + 地缘溢价。通胀粘性的根源之一。
操作：能源股（石油 / 煤炭）受益；航空 / 化工 / 物流等下游承压。
关注：油价 >100 警惕需求过热；<70 衰退信号。
美债 10 年--
人话：无风险利率偏高，全球估值锚压力大。所有长久期资产（消费 / 医药 / 科技）打折。
操作：减仓高 PE 成长股（特别是港股科技）；加仓低估值高股息（银行 / 红利 ETF）。
关注：10Y 跌回 4% 以下 = 估值压力释放 = 加仓信号。
美国 CPI 同比--
人话：通胀粘性，仍超 2% 目标。Fed 降息空间被压缩。
操作：耐心等 CPI 回到 2.5% 以下才是真降息预期，才是港股科技真机会。
关注：CPI 拐点（环比转负）= 关键转折信号。
10Y-2Y 利差--
人话：衰退先行指标未亮，曲线正常。
操作：暂时不需为衰退调仓；继续当前配置。
关注：利差转负 = 6-18 月内衰退概率大增。
NBER 衰退标记--
人话：距上次衰退 76 月 = 长扩张后期（历史平均 ~70 月），意味着衰退窗口随时可能开；估值要更保守。
操作：高 PE 标的需折价（30+ PE 要警惕）；现金 + 红利 ETF 加仓；不加杠杆。
关注：任何衰退先行信号（10Y-2Y 倒挂、就业反转）出现都要快速降仓 + 提现金比例到 30%+。
