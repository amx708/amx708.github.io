专科医疗怎么读：核心指标框架
医疗服务连锁的「单店—扩张—政策」三段式 · 框架级原创整理，不复制任何付费内容

为什么专科医疗不能用普通框架？
💡 一句话：专科医疗是「消费医疗 + 严肃医疗」的混合体：既看单店经济模型与扩张复制能力，又绕不开医保控费与民营准入政策，不能用纯消费或纯医疗任一框架硬套。

专科医疗是「消费医疗 + 严肃医疗」的混合体：既看单店经济模型与扩张复制能力，又绕不开医保控费与民营准入政策，不能用纯消费或纯医疗任一框架硬套。

1. 单店经济模型
1.1
单店回收期
眼科（屈光/视光）、牙科（种植/正畸）、体检的单店投资回收期、坪效与客单价，决定扩张的「算得过账」。
1.2
医生资源与品牌
核心医生是服务医疗的稀缺资产；品牌与口碑决定获客成本与复购，是连锁化的护城河。
2. 扩张与复制
2.1
自建 vs 并购
爱尔、通策以「分院 + 体内孵化」为主，美年以并购整合为主；复制能力决定扩张质量与商誉风险。
2.2
标准化与医患信任
服务标准化降低对个人的依赖，但医疗本质依赖信任，过度扩张会稀释品牌。
3. 政策与支付
3.1
医保控费 / 集采
人工晶体、种植体等耗材集采「以价换量」，服务费（手术/诊查）受控，挤压客单价但扩大可及性。
3.2
消费医疗自费属性
屈光、视光、种植多为自费，受居民消费力影响大，弱宏观下可选消费属性凸显。
4. 估值锚与风险框架
4.1
估值方法
连锁看 PE/PEG + 门店数与同店增速；并购型看商誉与整合后 ROE。低估值 + 稳健同店 = 安全边际。
4.2
风险框架
①医疗事故 ②扩张不及预期 ③政策控费 ④消费疲软。买点常在「估值低位 + 同店企稳 + 政策出清」时。
实用框架：先判行业周期位置，再看商业模式与壁垒信号，最后用估值分位 + 股息率定买点。分析框架见方法论文；行业周期脉络见价格/政策周期；行业内估值冷热见估值温度计；买点回测见三轮大底回测。
