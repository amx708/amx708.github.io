🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源中药护城河在“品牌 + 独家品种 + OTC 渠道 + 保密处方”。片仔癀（保密处方、稀缺原料，gpm 约 36%、npm 约 24%）、东阿阿胶（gpm 约 73%、npm 约 26%、roe 约 16.8% 复苏）凭稀缺性享溢价；济川药业（gpm 约 79%、npm 约 29%）、羚锐制药（gpm 约 80%、roe 约 22.3%）、江中药业（roe 约 22.5%、npm 约 21.5%）凭大单品 + 渠道高盈利。
2️⃣ 行业集中度与玩家分层行业呈“高毛利品牌 OTC（片仔癀 / 东阿 / 济川 / 羚锐 / 江中）vs 大健康混业（白云山 gpm 16%、npm 3.8%；同仁堂 gpm 43%、npm 6.9%）vs 处方中药承压（步长制药净利 CAGR 约 -20%、中药注射剂萎缩）”分化。本页 10 家涵盖央企（华润三九 / 同仁堂）+ 民企品牌。
3️⃣ 产业链上下游关系上游中药材种植 / 养殖 → 饮片 / 中成药制造 → 渠道（医院处方 + OTC 药店 + 线上）→ 消费者。品牌 OTC 对渠道与定价话语权强；处方中药受医保 / 集采与院内控费压制，向消费属性强的 OTC 集中。
4️⃣ 周期性与价格话语权弱周期、强消费：需求随健康消费稳步增长，不受宏观大幅摆动；但中药材价格周期（如阿胶原料、贵细药材）与政策（中药注射剂限制、集采）为关键变量。价格话语权集中于有品牌溢价与独家品种者。
5️⃣ 财务质量（盈利/分红/现金流）整体盈利质量高：品牌 OTC 自由现金流转好（江中 roe 22.5%、羚锐 roe 22.3%、东阿 npm 26%）；大健康混业薄利（白云山 npm 3.8%）；处方中药下滑（步长净利 CAGR -20%）。分红意愿分化，品牌现金牛最优。
6️⃣ 估值水位与历史分位按“品牌溢价 + 大单品放量 + 股息率”定价：稀缺品种（片仔癀）享稳定溢价，OTC 高 roe 标的看 PE 与分红；处方中药看政策触底。历史分位低 + 大单品稳健时为买点。
7️⃣ 主要风险事件清单中药材价格大涨、中药注射剂 / 处方品种政策限制、集采扩围、独家品种保护到期、品牌老化与渠道库存、消费疲软、原料（阿胶驴皮 / 贵细）供给波动。
8️⃣ 投资跟踪指标与反向信号跟踪：重点大单品增速、中药材价格 index、OTC 渠道库存、股息率、政策（中药注册 / 集采）、各公司毛利率与经营现金流。

📦 产品定位与投资信号

产品分品牌 OTC（片仔癀 / 东阿阿胶 / 济川 / 羚锐 / 江中）、处方中药（步长 / 以岭）、大健康混业（白云山 / 同仁堂 / 华润三九）。投资信号：稀缺品种与高毛利 OTC 优，处方中药承压。

🏛 竞争格局分析

央企（华润系 / 同仁堂）与民企品牌并存，品牌 + 独家品种构筑壁垒；本页 10 家盈利分化极大：济川 gpm79% / 东阿 npm26% vs 步长净利 CAGR-20%。OTC 龙头集中度高、处方端受集采挤压。

🔄 产能周期与库存周期

产能随品种与产线扩张，稀缺原料（天然麝香 / 驴皮）约束供给；消费属性强、需求平稳，无强周期产能波动。扩建多为产能升级与产能利用率提升，供给端弹性小。

🔄 中药产业链 产业周期怎么看

驱动变量：医保/基药目录调整、OTC 提价能力、中药材价格周期（成本）、国企改革与机制理顺、消费属性（保健品/养生）。

  • 中药材价格指数（如康美·中国中药材价格指数）：上行 → 成本压力、考验提价传导；回落 → 毛利修复。
  • 政策：中医药振兴、基药/医保放量、国企改革（混改/激励）释放经营活力。
  • 消费：可选消费景气影响保健品与礼品属性品种。
  • 提价权：品牌 OTC（独家品种）具备定价权，可对冲成本。
当前位置（定性框架，非数据结论）：中药周期看"药材价格+政策+消费+提价权"：当前药材价格高位波动、消费偏弱，具备定价权与改革红利的龙头更稳，关注基药目录与国企改革催化。
