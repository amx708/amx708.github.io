炼化（炼油+石化）方法论（六段）

1. 行业特殊性：化工产业链的中间环节

炼化是「夹在原油与终端」之间的两端挤压型生意。油价低+ 终端旺时最赚钱（库存收益 + 价差扩大）；油价高 + 需求弱时双杀。本质是赚加工费，所以估值天花板不应高于加工服务行业（PE 15-20）。

2. 估值的四个概念：吨毛利 × 价差 × 一体化深度

炼化的核心估值不是 PE / PB，而是：① 吨毛利（元 / 吨加工量）；② 汽柴油 - 原油价差（裂解价差）；③ PX - 石脑油价差；④ 一体化深度（从原油到终端的距离）。当前 A 股民营四巨头 ROE 中位 ~7%，对应合理 PE 12-18、PB 1.5-3.0。

3. 当前行业锚（2026-08 快照）

布伦特 75 美元 / 桶（中性）；PX - 石脑油价差 200-300 美元 / 吨（中性偏低）；纺服需求温和复苏（终端弱好转）；炼厂开工率 78%（中性）；化工品库存压力下降。本链处于筑底阶段，民营四巨头具备 biddable 价值。

4. 阶段演进：从 FCC 催化裂化到煤制 / 乙烷制

① 传统炼化（2000-2015）：以 FCC 路线为主；② 大型一体化（2015-2023）：浙石化 / 恒力 / 盛虹千万吨级投产；③ 工艺分化（2023+）：煤制烯烃（宝丰）、PDH（卫星）、特种橡胶等差异化路线。本链处于第三阶段，工艺效率成为超额收益来源。

5. 买点清单与风险

买点 checklist：① 油 - 化 - 纺一体化深度 ≥ 3 环节；② 工艺成本在中位以下（民营 vs 国资 / 煤制 vs 油制）；③ 资本开支高峰已过；④ ROE 历史均值 ≥ 10%；⑤ 库存周期触底信号（PMI / 纺服出口回升）。主要风险：① 油价大幅波动；② 产能过剩加剧；③ 环保 / 安全事故；④ 替代工艺路线冲击（如 EV 削弱成品油需求）。

6. 回链 7 兄弟页与方法论
