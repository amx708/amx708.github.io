🎯 投资逻辑（8 条 · AI 填实 · 通用银行投研框架）

8 条逻辑对应银行投研的 8 个核心分析维度。每条给出该维度可观察的跟踪指标（不编具体数字）。后续针对本链需要补充的具体判断口径由人工补。

1️⃣ 银行商业模式：负债端成本 → 资产端定价 → 息差管理牌照护城河 + 规模效应。观察：存款付息率走势、活期占比、同业负债比重、零售/批发存款结构。
2️⃣ 资产质量：不良率 / 关注类 / 逾期 90 天以上 / 拨备覆盖率信用风险定价的真实暴露。观察：不良迁徙率、新生成不良率、逾期 90 天以上/不良偏离度、拨贷比、抵押贷款占比。
3️⃣ 净息差（NIM）与资产负债结构：期限错配 + 重定价节奏息差是银行利润表最大变量。观察：贷款重定价期限分布、按揭/对公/小微/消费贷结构、债券投资久期、LPR 切换进度。
4️⃣ 拨备与反哺能力：拨贷比 / 信用成本 / 利润释放空间拨备池是银行利润的蓄水池。观察：信用成本率、拨备覆盖率与监管底线差、逆周期计提节奏、非信贷减值占比。
5️⃣ ROE 与资本约束：核心一级 / 资本充足率 / 分红节奏ROE 中枢由杠杆与资本容量决定。观察：核心一级资本充足率、内生资本累积、外源融资计划、分红率与节奏、TLAC 达标进度。
6️⃣ 估值水位：PB 历史分位 vs 股息率 vs ROE 匹配度银行估值不能只看 PE，必须看 PB-ROE-Payout 三角。观察：PB 5/10 年分位、股息率与 10Y 国债利差、ROE 与净资产增速匹配度。
7️⃣ 主要风险：地产 / 地方债 / 零售信贷 / 汇率 / 监管资本新规自下而上检查风险敞口。观察：对公房地产贷款占比 + 关注类、地方政府融资平台敞口、零售消费贷逾期率、跨境业务净敞口、TLAC/IRRBB 合规进度。
8️⃣ 跟踪指标：社融 / 信贷投放 / 息差走势 / 不良迁徙率宏观景气→银行基本面传导的关键高频指标。跟踪：月度社融与信贷结构、上市银行季报息差、不良迁徙率与核销节奏、央行 LPR/MLF 政策。

📦 产品定位与投资信号

待人工填实：①国有大行（工/农/中/建/交+邮储）— 对公压舱石，全国网点；②股份制行（招/兴/浦/民/中信等）— 零售+对公双轮；③城商行（宁波/江苏/北京/上海/南京等）— 区域龙头；④农商行（常熟/无锡/紫金/苏农等）— 小微下沉。
每家核心看点：净息差水平、零售存款占比、手续费收入占比、ROE 稳定性。

🏛 竞争格局分析

待人工填实：①总资产 CR5/CR10 集中度走势；②国有大行与股份行的对公地盘变化；③城商行省内集中度与跨省扩张窗口；④外资/互联网平台对零售业务的边际冲击。
可量化锚点：净息差分层（国有 < 股份 < 城商/农商）、不良率分层、ROE 分层。

🔄 产能周期与资产质量周期

待人工填实：①信用周期阶段（社融存量/信贷投放同比）；②不良生成率与核销节奏；③拨备覆盖率是否进入反哺期；④资本充足率对分红/再融资的约束。
关键跟踪：监管让利节奏、地产敞口暴露、消费贷与小微风险演化。
