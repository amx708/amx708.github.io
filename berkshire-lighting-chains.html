产业周期判断标准
🔄 照明产业链 产业周期怎么看

驱动变量：照明是成熟制造业，景气周期由四个互相牵制的变量决定——需求、政策、技术迭代、原材料。通用照明需求随地产 / 消费走平；政策（节能补贴）与出口托底；LED 技术迭代放缓后进入成本与份额竞争；原材料（铝 / 铜 / 塑料）影响毛利。

  • 需求（量）：家居 / 商业 / 工程照明随地产与消费；车规 / 植物 / UV 等新场景是增量。看照明周期，需求决定「水位」。
  • 政策（刺激）：节能补贴、以旧换新、绿色照明推广是政府对冲需求下行的主要抓手。补贴延续性、品类扩围（从通用到智能 / 车规）是关键观测。
  • 技术迭代（结构）：LED 替换高峰已过，增量在车规 / 智能 / 健康照明。技术红利从「渗透率提升」转向「单值提升」。
  • 原材料（成本）：铝 / 铜 / 塑料是主要成本。原材料下行→毛利修复；上行→龙头凭规模与套保对冲，中小承压。
  • 份额集中（α）：行业β弱时，龙头凭渠道、品牌、现金流份额逆势提升，是穿越周期的重要α。

周期判断框架：当四个变量中「需求（地产 + 政策 + 出口）」与「成本（原材料）」同向向好时，行业景气上行；反向时进入分化，龙头靠α跑赢；双弱时进入周期底部，出清与份额提升是观察重点。当前更关注「结构性α」而非「总量β」。

当前位置（定性框架，非数据结论）：当前阶段：通用照明需求饱和、价格战延续；但车规 / 智能 / 植物照明等细分景气向上，龙头凭规模、出海与高分红穿越周期。行业整体「β弱α分」，结构性机会大于总量机会。最值得跟踪：补贴延续性、车规 / 智能渗透节奏、原材料价格拐点、出口与汇率。

产业链成本传导 · 上游原材料 → 毛利

照明成本以 LED 芯片、封装、驱动电源、铝材 / 塑料结构件为主。芯片国产化与规模效应持续压低成本，但通用照明价格战使降本难以转化为毛利。

上游原材料（铝 / 铜）价格波动直接影响外壳与散热件成本；龙头凭规模采购与套保平滑波动，中小厂商在价格上行期被动跟涨、下行期被迫降价。

怎么读：看分位：在通用照明产能过剩、价格战延续下，谁 PB 仍处低位、谁已透支，分位表一目了然。车规 / 智能照明因壁垒更高，估值溢价有基本面支撑。
