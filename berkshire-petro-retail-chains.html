成品油零售板块是石油石化产业链的「末端环节」，最贴近消费者端。A 股零售主要包括：① 中石化子公司（泰山石油/岳阳兴长，依赖集团供油）；② 民营加油站连锁（和顺石油）；③ 综合能源化工兼营（四川美丰/大庆华科）。零售本质是「批零差」生意，毛利薄（5-8%）但稳定，且非油业务（便利店/洗车）有结构性增量。

🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源油品零售护城河在区域加油站网点 + 特许经营牌照 + 稳定成品油吞吐。区域标的中泰山石油（营收约 32 亿、roe 约 13.9%、npm 约 4.9% 相对最优）、广聚能源 / 国际实业微利；多数小市值标的受油价与新能源替代冲击盈利薄。
2️⃣ 行业集中度与玩家分层行业呈“区域加油站运营商（泰山 / 和顺 / 广聚 / 国际实业）+ 炼厂贸易延伸（茂化实华 / 岳阳兴长 / 四川美丰 / 沈阳化工 / 大庆华科）”格局。盈利普遍微利或亏损：茂化实华（roe -28%、净利 -1 亿）、四川美丰 / 岳阳兴长（各 -1 亿）、和顺石油 / 沈阳化工微亏。本页 9 家多为小市值、盈利质量弱。
3️⃣ 产业链上下游关系上游成品油（三桶油批发）→ 油库 / 加油站分销 → 终端车主。零售商对进销价差无定价权（随发改委调价），利润取决于网点吞吐、非油业务与单站效率，向有优质区位网点的区域龙头集中。
4️⃣ 周期性与价格话语权弱周期、受替代冲击：需求随车用油平稳但受电动化长期替代；价差由政策调价锚定，价格话语权弱。新能源（充电 / 换电）是核心结构性逆风，护城河来自牌照与区位而非定价。
5️⃣ 财务质量（盈利/分红/现金流）整体薄利：仅泰山石油 roe 13.9% 相对健康，其余 roe 多 <2% 或亏损（茂化 -28%、和顺 -1.4%）。自由现金流受网点资本开支与库存影响，分红弱、扩张意愿低。
6️⃣ 估值水位与历史分位按“单站利润 + 股息率 + 网点价值”定价：区域龙头看 PB（破净常见）与重置成本；新能源替代压制估值。历史分位低 + 高分红时为价值买点，但需警惕需求长期下行。
7️⃣ 主要风险事件清单成品油需求被电动化替代、批零价差收窄、新能源（充电桩）竞争、网点租赁与重置成本、库存跌价、安全监管、区域牌照政策变化。
8️⃣ 投资跟踪指标与反向信号跟踪：成品油表观消费量、加油站单站销量、批零价差、新能源车渗透率、各公司股息率与网点、非油业务进展。

📦 投资逻辑附加：产品定位 / 竞争格局 / 产能周期（占位）

📦 产品定位与投资信号

产品为成品油零售（汽油 / 柴油）+ 非油便利店业务；部分标的兼炼厂贸易延伸（化工品）。投资信号：区域网点价值 + 单站效率，新能源替代是核心逆风。

🏛 竞争格局分析

中石化 / 中石油自营站主导，民营区域站（泰山 / 和顺）补充；本页 9 家小市值为主，盈利分化：泰山 roe13.9% vs 茂化实华 roe-28% / 多标的微亏。区域分割、同质化竞争。

🔄 产能周期与库存周期

加油站为特许经营重资产，网点受牌照与区位约束、供给端刚性；单站吞吐随区域车流。新能源充电网络扩张形成替代产能，成品油需求见顶预期下新增加油站意愿低。

加油站供给侧收紧

国家 2024 年起原则上不再新增城区加油站审批，存量加油站资产进入稀缺化阶段。中石化 / 中石油 / 民营头部企业的现有网络估值将提升。

新能源对加油站流量的分流

充电桩对加油站客流的影响已显现 —— 高速服务区场景分流明显，但城市核心区加油站仍稳定。未来 5 年加油站可能演变为「油 + 电 + 综合能源」站，非油业务占比将提升到 20%+。

非油业务的毛利贡献

中石化易捷便利店非油毛利 25%+，与油品毛利 5-8% 形成对比。山东泰山石油这类依赖大股东供油的子公司，非油业务占比低是 ROE 上行的瓶颈。

批零差机制的保护

国内成品油定价机制下，油价大幅波动时批零差保持 1000-1500 元 / 吨（保护性）。也就是说零售板块 ROE 波动远小于上游 / 炼化，是防御性配置标的，适合低风险偏好。

油品升级的隐性利好

国 VI B 汽油全面推广，单车加油频次微降但单价上升，加油站整体收入大致稳定。同时新能源车占比上升使加油站需要转型投入，现金流压力是中期挑战。

跨层五维分析

1. 批零差：成品油零售的本质

国内加油站毛利率约 5-8%，主要来自批发价（炼厂出厂）到零售价（加油站挂牌）的差额。中石化子公司的优势是「集团供油成本价内部结算」，但劣势是决策慢、运营效率低；民营加油站（和顺）的优势是灵活选址 / 单店优化。

2. 非油业务收入的结构性增量

成熟加油站非油业务（便利店 / 洗车 / 广告 / 餐饮）毛利 20%+，是 ROE 提升的关键。中石化「易捷」便利店 28,000+ 店贡献非油业务 ~150 亿营收；民营和顺石油非油占比仅 5%，结构性差距明显。

3. 加油站选址与排他性壁垒

加油站是区位依赖型业务：城市规划一旦成熟，新增加油站审批极难。所以存量加油站位置比经营效率更重要。中石化依托早期布局占据全国 30%+ 份额，民营加油站只能在三线城市或新城区增量。

4. 油价波动对零售的双向影响

油价上涨期：库存收益 + 批零差扩大，零售利润 先升后降（滞后期 2-3 个月）；油价下跌期：库存损失 + 批零差缩小，零售利润 先降后稳。

5. 零售标的的估值特点

零售板块 ROE 普遍个位数（5-15%），PE 分位通常 < 30%（市场认为是「老旧业务」），PB 是更有效估值锚：稳态 ROE 10% 对应合理 PB 1.0-1.5，ROE 15% 可至 PB 2.0+。泰山石油 ROE 14.22% / PB 2.51 估值偏贵；广聚能源 ROE 4.12% / PB 1.49 估值相对合理。

成本传导：油价 / 煤价 / 石脑油价如何影响本链
原料端： 上游：原油采购（占成本 50-70%），OPEC+ 减产 / 地缘冲突（如红海航运）可短期推升 10-30% 炼化：原油 + 石脑油 + 煤炭 / 天然气（煤制烯烃路线） 零售：批发价（炼厂出厂） + 物流费（短驳 / 长输） 加工端： 折旧（炼厂/管网/加油站投入大）+ 人工 + 能耗（电/蒸汽） 一体化项目（浙石化/恒力）规模效应使吨成本低于行业 10-15% 销售端： 批零差（成品油定价机制：10 个工作日调整一次） 加油站毛利率 5-8%（轻油）+ 非油业务毛利 20%+（便利店/广告） 传导结论： • 油价 ↑ 80 美元/桶时：上游净利 +30%，炼化毛利被挤压（最优炼油价差 5-10 美元/桶） • 油价 ↓ 50 美元/桶时：上游资源价值打折，炼化库存收益 +5-10% • 煤价 ↑ 时：宝丰能源（煤制烯烃）成本压力大；广汇能源煤化工利润同步承压
