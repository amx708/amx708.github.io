人话版：这个框架怎么用
💡 一句话：软件看的是「能不能从卖授权转订阅（粘性）+ 信创/AI 给不给增量 + 估值贵不贵」

投资软件产业链的关键是看清「周期位置 + 护城河 + 估值锚」：从上游到下游，每一层都有可跟踪的硬指标。

5 层框架其实是回答三个问题：

  • 上游：底座谁定？ 云 / 算力 / 操作系统是软件运行底座，信创（国产 OS/数据库）重构底层；国产底座突破利好上层应用。
  • 中游：做什么产品？ ERP（用友）、办公（金山）、造价（广联达）、金融IT（恒生）、信创（中国软件、太极）、OA（泛微）、工业软件（宝信、中望）、AI（讯飞）；订阅化提升收入韧性。
  • 下游：谁买单？ 政企 / 金融 / 制造是核心客户，其 IT 预算决定付费；信创与 AI 是增量预算来源。
  • 需求：长期钱在哪？ 自主可控（信创）+ AI 重构是 10 年级长坡，从工具到智能体范式迁移打开空间。
  • 投资逻辑：安全边际在哪？ 软件买点多在「订阅化兑现 + 估值回调」，高毛利 + 弱周期；但 ToB 付费谨慎、估值易高。

实战信号：信创放量 + AI 落地 → 金山 / 恒生 / 讯飞受益；ToB 预算收缩 → 用友 / 广联达承压。当前估值分化，安全边际来自订阅化与盈利兑现。

产业周期判断标准
🔄 软件产业链产业链 产业周期怎么看

驱动变量：驱动变量：政企 IT 预算（信创节奏）、AI 应用落地（付费意愿）、云 / 订阅渗透率、宏观经济（ToB 付费能力）。这是「政策—技术—预算」三段式成长周期。这是「政策—成本—需求」三段式周期，而非传统产能周期。

  • 信创节奏：党政 / 行业放量 → 国产软件订单增；放缓 → 收入递延。
  • AI 落地：付费意愿强 → 增量收入；不及预期 → 投入打水漂。
  • 订阅渗透：转云顺畅 → 收入韧性升；受阻 → 波动大。
  • 宏观预算：景气 → ToB 付费强；收缩 → 项目延期。

举例说明：2023–2025 信创（党政 / 金融 / 电信）放量 + AI Copilot 式应用落地，金山 / 恒生 / 讯飞受益；2022 前 ToB 预算收缩则用友 / 广联达增长放缓。

当前位置（定性框架，非数据结论）：当前位置（定性框架，非数据结论）：软件处「信创 + AI 重构早期 + 估值分化」期，高毛利弱周期、订阅化提升韧性；变量是信创节奏与 AI 付费，安全边际来自订阅化与盈利兑现。

产业链成本传导

本产业链的成本传导链为：云/算力底座 → 软件产品 → 行业客户 → 订阅收入。软件产业链没有交易所统一期货（无统一定价期货），成本传导以定性框架 + 周期呈现。

软件无统一期货，成本传导以「底座 → 产品 → 客户 → 订阅收入」定性框架呈现：信创底座突破 → 国产软件替代放量。

向上游看：国产 OS / 数据库突破重构底层，利好上层应用（中国软件、太极）但研发成本高。

向中游看：订阅 / 云转型提升收入韧性与毛利，AI 重构打开空间；估值分位见上，反映「估值分化」。
