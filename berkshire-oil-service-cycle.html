周期脉络：十年一图
🔄 一句话：油服装备 的「周期」是供需 + 政策 + 地缘的叠加

油服装备是上游勘探开发的「卖铲人」：景气由油价 → 三桶油资本开支 → 油服订单与日费率传导，并叠加出海（中东 / 俄罗斯 / 中亚）订单弹性。

年份主线事件对行业影响
2015油价腰斩Brent 从 ~115 跌至 ~37，三桶油大幅砍资本开支，油服订单断崖，中海油服 / 海油工程业绩大降。
2016OPEC+ 减产油价修复至 ~55，上游 capex 触底，油服处于最艰难阶段但现拐点信号。
2017温和复苏油价中枢 ~55，国内「增储上产」启动，海工 / 钻探订单边际改善。
2018高位震荡油价冲高至 ~85，上游资本开支回暖，但油服产能仍过剩、日费率低位。
2019能源安全加码贸易摩擦下油价回落 ~65，国内能源安全战略升温，「七年行动计划」提振油服中长期需求。
2020疫情黑天鹅Brent 一度负值，全球上游 capex 砍 30%+，油服订单蒸发、海工装备重创。
2021复苏反弹油价回 ~70，capex 恢复，油服日费率与利用率回升，业绩弹性释放。
2022俄乌冲突Brent 冲 ~120，能源安全 + 高油价推动全球 capex 强反弹，油服超级景气，中海油服创纪录。
2023高位回落油价回落至 ~80，capex 仍强但增速放缓；出海（中东 / 俄）成为新增长极，内部分化开启。
2024出海加速国内 capex 平稳，中东 / 中亚 / 俄罗斯订单放量，杰瑞 / 中曼 / 博迈科海外占比提升，分化加剧。
2025结构分化油价中枢下移，国内 capex 以质换量；具备出海 + 技术壁垒的龙头（杰瑞压裂、中海油服钻井）alpha 凸显，纯内卷者承压。
关键指标与周期信号
信号①

油价→capex 传导

油服订单滞后油价约 2–4 个季度，且由上游资本开支周期而非即期油价决定；capex 上行是订单与日费率回升的前置信号。

信号②

中海油 Capex 与增储上产

国内能源安全下中海油「增储上产」提供内需基本盘，中海油服 / 海油工程的国内订单有较强确定性。

信号③

出海弹性

杰瑞（压裂设备）、中曼（钻井工程）、博迈科（海工模块）的中东 / 俄罗斯 / 中亚订单，是对冲国内周期的关键 alpha 来源。

信号④

估值锚

油服多为高 PB / 高 PE 分位（成长 + 出海叙事），买点看订单可见度与日费率，而非单纯低估值；现金流与负债率决定安全边际。

周期位置是买点判断的「地图」而非「导航」：框架告诉你行业在周期哪一段，但拐点何时出现需结合实时供需与政策验证。结合 估值回测 与 横向对比 综合决策，不构成投资建议。
