周期股涨价逻辑攻略

一套用于筛选"产品涨价→股价未反映"错配机会的通用研究框架。适用于化工、有色、建材、农产品等强周期行业，本质是用公开价格数据寻找信息差与安全边际。

本页为方法论与历史案例整理，不构成任何投资建议；所有数据均标注来源与时间，过时数据请自行复核。

① 涨价逻辑到底是什么

一句话：当一家公司的主营产品价格持续上涨，而市场还没有把这份利润预期打进股价时，就出现了"错配"——这是周期股最核心的超额收益来源之一。

它赚的不是"长期价值成长"的钱，而是"价格周期反转 + 预期差"的钱。价格由供需决定，股价由预期决定；两者之间天然存在时间差，框架的作用就是捕捉这个时间差。

发动机
产品价格
没有价格动，一切免谈。价格是唯一因，利润与股价都是果。
机会本身
价股错配
价涨了、股没跟 = 预期未打满 = 安全边际。这是"买点"的本体。
可持续性
供给硬约束
事故/检修/环保/矿权造成的缺口，比情绪拉涨更暴利、更持久。
适用边界：强周期、产品有公开报价、成本曲线清晰、供给端易出"黑天鹅缺口"的行业最有效（化工、有色、建材、农产品、航运等）。对消费、科技等弱周期或定价权在需求端的行业，框架需大幅打折使用。

② 三大核心指标（仪表盘）

把复杂框架浓缩成每天只需盯的三个数字。其中前两个是"机会窗口"，第三个决定"值不值得做"。

重要性指标看什么经验阈值
第一 产品价格变化率
月涨% / 周涨%		 涨价逻辑的发动机。月度看趋势，周度看"急涨冲击"。 月度门槛：化工 10–15%、有色 6–10%；周涨≥20% 视为供给冲击
第一 价股错配度
= 价月涨% − 股月涨%		 价涨、股没跟 = 预期未打满 = 安全边际。这是"机会"本身。 价涨≥门槛 且 股月涨<价的 60% → 错配买点
第二 业绩弹性 ΔEPS
≈ 涨价额×年产量÷股本		 决定"这波涨价值不值得做"，避免小题大做、被稀释。 弹性小（占比低/成本同涨）直接 Pass
最简记忆：真正每天只需看一个核心数字 —— 「产品价格月涨幅 − 代表标的股价月涨幅」。 它是正且够大 = 机会；它是负（价涨股跌）= 撤退信号。其余指标都是给这个数字做背书或排雷的。

③ 四大决定因素（能不能做）

指标告诉你"窗口出现了"，这四个因素判断"这个窗口能不能进、能进多大"。

🥇 确定性（第一原则）

只在高确定性错配上下注，不确定就轻仓或旁观。确定性来自：价格已真实落地（非传闻）、供需缺口可验证、公司受益路径清晰。

反面：赌情绪、赌题材、赌"可能要涨" —— 多半接盘。

🥈 信息差 / 数据源

中游产品价格（维生素、纯碱、磷矿石）关注度远低于上游期货，每日盯百川盈孚、卓创、生意社等报价即拥有超额信息。

反面：等新闻满天飞才看到 → 往往已是卖点。

🥉 供给端硬约束

事故、检修、环保限产、矿权稀缺导致的供给缺口，才是最暴利且可持续的涨价（如装置爆炸致 VA 冲高）。

反面：纯情绪/资金拉涨、无供给约束 → 不可持续、易回吐。

🥉 成本曲线位置

低成本龙头（天然碱、自有矿山）弹性最大：价跌它最后亏、价涨它最先赚；价涨它吃满利润。

反面：成本曲线右侧、纯冶炼加工 → 涨价也分不到多少利润。

两个不能忽视的附加因子：
  • 产品占主营比重（exposure）：占比 < 20% 时"价涨利不涨"，弹性被严重稀释，必须一票否决或下调权重。
  • 股价领先定价（最重要风险因子）：股价通常领先商品 6–12 个月见顶，所以"价还在涨、股已跌"= 派发警惕，而不是买点。

④ 五步法（落地流程）

  1. 抓价格信号：每日跟踪"中游产品"报价（维生素/纯碱/钛白粉/磷化工/铜锂铝），优先选关注度低、信息差大的品种。
  2. 算业绩弹性：ΔEPS ≈ 涨价金额 × 年产量 ÷ 总股本。先算弹性再决定是否值得研究。
  3. 找错配：产品价格涨、股价未涨 = 安全边际。用"价股错配度"量化，正且够大才是真错配。
  4. 择时：拐点 + 加速段买入；财报季（1/4/7/10 月）是预期兑现窗口，遵循"买预期、卖事实"。
  5. 退出：周期下行即清仓，不赚最后一段；人声鼎沸、新闻刷屏时反而警惕。

⑤ 化工实例（含硬数据）

品种 / 标的涨价逻辑关键数据类型
维生素（新和成 / 浙江医药） 海外大厂装置爆炸/不可抗力 → 供给缺口 → VA/VE 暴涨，国内龙头直接吃满利润。 VA 从约 75 元/kg 冲至 290–300 元/kg；新和成 2024 年净利 +117%。 供给冲击型
纯碱 / 天然碱（远兴能源） 天然碱法成本远低于氨碱/联碱，处于成本曲线最左端，价格回暖时弹性最大。 低成本 + 大产能 = 周期反转首选弹性标的。 低成本龙头
钛白粉（龙佰集团） 成本传导型：看"量价齐升"还是"价涨量缩"。钛精矿成本是利润锚。 需同时跟踪钛精矿价格与出口订单，避免"价涨但成本同步涨"。 成本传导
磷化工（兴发 / 云天化） 磷矿权稀缺 + 新能源（磷酸铁锂）需求增量，矿端供给硬约束。 矿自给率高的标的弹性显著优于外购矿企业。 资源约束
化工要点：化工品的涨价多由"装置事故 / 检修 / 环保"触发，持续时间看缺口大小；优先选单品占比高 + 成本曲线左端的龙头。

⑥ 有色实例

品种 / 标的涨价逻辑关键数据类型
铜（紫金矿业） 铜价是估值"量尺"。只选高自给率矿山股，纯冶炼无弹性。 铜价每涨 1000 美元/吨 → 紫金净利约 +35~40 亿元。 资源弹性
锂（天齐 / 赣锋） 碳酸锂强周期，price 由供需缺口主导；最关键的规律：股价领先商品见顶。 碳酸锂 2021 初约 5 万 → 2022.11 最高约 60 万 → 2023 跌至约 10 万；天齐 2022 净利 241 亿(+1060%)；天齐股价 2021.09 即见顶，锂价 2022.11 才见顶。 领先见顶
铝（神火 / 云铝） 价格 × 电力成本双变量；水电铝成本低且减碳溢价。 需同时看铝价与电价/煤炭成本，成本端不失控才有弹性。 双变量
黄金（山东黄金） 宏观对冲属性，与实际利率、避险需求负相关，与周期商品逻辑不同。 更多作为组合"防御垫"，而非弹性进攻品种。 对冲垫
锂的教训：商品还在新高、股价早已腰斩——这就是"股价领先商品 6–12 个月见顶"。看到"价涨股跌"千万别当错配买点，那是派发/撤退信号。

⑦ 规律与陷阱（必须记牢）

规律一：股价领先商品见顶

周期股炒的是"未来预期"，不是"当前价格"。商品见顶前半年，股价往往已提前反应。所以商品新高 ≠ 还能买。

规律二：涨价 ≠ 利润涨

占比小、成本同步涨、涨价时长短，都会稀释弹性。先算 ΔEPS，再谈机会。

规律三：信息差在"中游"

上游期货人人看，超额收益薄；中游产品报价冷门，才是错配温床。建立自己的数据源 = 建立护城河。

规律四：不赚最后铜板

人声鼎沸、新闻刷屏即警惕。周期品利润兑现最快，反转也最快，留一段给别人。

⑨ 如何搭建监测系统

把以上框架工程化，做成一个每日自动跑、自动推送的监测器。最小可用架构：

监测清单(watchlist) + 行情数据源(可插拔) → 信号引擎 → 看板(report.html) + 推送文本(alerts.txt)

信号引擎五类判定

信号触发逻辑动作
供给冲击周涨 ≥ 20%（事故/不可抗力型急涨）重点跟踪
错配买点价月涨≥门槛 且 股月涨仅为价的 0~60%研究建仓
价涨股跌·警惕价月涨≥10% 但股价月跌（领先见顶）减仓/勿追
周期下行·退出价月跌 ≥ -15%考虑退出
趋势中·已反映价涨、股同步涨持有观察

数据源可插拔

  • 期货/有色：akshare（免费，pip install akshare）可取铜、锂、铝、金等期货与个股行情。
  • 化工品：生意社 / 百川盈孚 等报价接口（低价位付费即可，符合小预算），覆盖维生素、纯碱、钛白粉、磷矿石。
  • 演示模式：先用静态 sample_data 跑通逻辑，再替换为实盘 Provider。

工程化后可用定时任务每日收市后运行，把机会/风险摘要推送至邮箱或 IM。本页同源工程已包含 Python 信号引擎与可运行演示。

⑩ 风险与免责

核心风险：
  • 周期反转极快，商品见顶前股价已先行，追高易被埋。
  • 涨价持续性难判断，短促脉冲型涨价弹性被稀释。
  • 成本同步上涨会吞噬利润，需动态复核成本曲线。
  • 框架是"研究/排雷工具"，不是下单机器；信号只提示错配，买卖仍须结合个人安全边际。
