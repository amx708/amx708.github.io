🔄 厨电产业链 产业周期怎么看

驱动变量：厨电是地产后周期典型行业，景气周期由四个互相牵制的变量决定——地产、政策补贴、集成化升级、原材料。新房竣工与二手房装修是烟灶与集成灶的β来源；以旧换新托底存量更新；集成化 / 高端化提高单值；原材料影响毛利。

  • 地产（需求β）：新房竣工与二手房装修是厨电β来源。地产上行→新增与精装配套放量；下行→存量更新与局部装修对冲。看厨电周期，地产决定「水位」。
  • 政策补贴（刺激）：以旧换新、节能补贴、消费券是政府对冲地产下行抓手。厨电品类扩围（从烟灶到集成灶 / 洗碗机）是关键观测。
  • 集成化升级（α）：集成灶 / 集成烹饪中心 / 洗碗机提高客单价与渗透，是穿越周期的结构性α。关注渗透率拐点与高端化。
  • 原材料（成本）：钢板 / 玻璃 / 铜铝是主要成本。原材料下行→毛利修复；上行→龙头凭规模套保对冲。
  • 份额集中（α）：老板方太双寡头（烟灶）、集成灶专业玩家、小厨电美苏九。行业β弱时龙头份额逆势提升。

周期判断框架：当四个变量中「需求（地产 + 政策 + 出口）」与「成本（原材料）」同向向好时，行业景气上行；反向时进入分化，龙头靠α跑赢；双弱时进入周期底部，出清与份额提升是观察重点。当前更关注「结构性α」而非「总量β」。

当前位置（定性框架，非数据结论）：当前阶段：地产竣工端仍偏弱，但以旧换新与存量更新托底内销；集成化（集成灶 / 集成烹饪中心 / 洗碗机）与高端化提高单值；出口保持韧性。行业整体「β弱但α分」，龙头靠份额集中与高端化穿越周期，结构性机会大于总量机会。最值得跟踪：补贴延续性、集成化渗透节奏、原材料价格拐点、出口与汇率。

产业链成本传导 · 上游原材料 → 毛利

厨电成本以钢板、玻璃、电机、控制器为主，原材料占成本比重高。原材料下降→毛利扩张，上行→成本传导有滞后，龙头更能转嫁。

上游价格波动通过钢材 / 铜铝传导到整机场；龙头（老板 / 方太 / 苏泊尔）凭规模、套保与高端化提价保住毛利，中小品牌被两头夹击。

怎么读：看分位：在地产链偏弱、行业β弱时，谁 PB 仍处低位、谁股息率创近年新高，分位表与 R15 表一目了然。集成化与出海是α来源。
