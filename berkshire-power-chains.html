🎯 投资逻辑（8 条 · AI 填实（基于 10 年财报））

1️⃣ 商业模式与护城河来源电力护城河分源而异：水电靠流域垄断与不可复制的坝址（长江电力 gpm 约 62%、npm 约 40%、roe 约 15.6%，自由现金流极强）；核电靠牌照 + 技术壁垒（中国核电 gpm 约 41%，装机稳步扩张营收 CAGR 约 12%）；火电与新能源发电靠规模与资源区位，壁垒相对较弱。
2️⃣ 行业集中度与玩家分层行业呈“水电现金牛 > 核电稳定成长 > 新能源扩张期 > 火电周期薄利”分层。长江电力 / 中国核电为盈利质量标杆；三峡能源 / 龙源电力新能源装机高增（三峡营收 CAGR 约 21%）但重资产折旧压低 roe（4%-6%）；火电五大（华能 / 华电 / 大唐 / 国电 / 粤电力）净利率仅 4%-6%，粤电力 A 近乎微利（npm 约 1.2%）。
3️⃣ 产业链上下游关系上游燃料（煤 / 铀）/ 风光资源 → 发电运营 → 电网统购统销 → 终端用户。运营商对电价无定价权（输配电与政府定价），利润取决于资源禀赋、利用小时与燃料成本，向低成本电源（水电 / 核电）集中。
4️⃣ 周期性与价格话语权强管制 + 弱周期：需求随经济平稳增长，电价受政策锚定；火电受煤价周期剧烈摆动（粤电力净利 CAGR 约 -16%），水电来水、核电审批节奏为关键变量；价格话语权弱，护城河来自资源而非定价。
5️⃣ 财务质量（盈利/分红/现金流）水电自由现金流与分红最厚（长江电力 roe 15.6%、npm 40%）；核电稳健（中国核电 roe 7.8%、npm 11.3%）；火电薄利且受燃料拖累（华电国际净利 CAGR 约 -2%）；新能源扩张期 roe 偏低但现金流随装机改善。整体分红意愿强、资本开支前置。
6️⃣ 估值水位与历史分位按“类债属性 + 股息率 + 利用小时”定价：水电 / 核电享受稳定溢价，火电看煤价与容量电价、PB 贴近 1 倍；新能源看装机增速与电价退坡。历史分位低时股息率保护足，适合作为组合压舱石。
7️⃣ 主要风险事件清单来水偏枯、核电机组检修 / 审批放缓、煤价大涨、新能源电价退坡与消纳受限、容量电价政策变化、利用小时下滑、电力市场化交易价差扩大。
8️⃣ 投资跟踪指标与反向信号跟踪：水电来水与蓄能、核电核准与装机、火电煤价与利用小时、新能源新增装机与平价电价、各公司股息率与自由现金流、容量电价政策落地。

🔄 电力产业链 产业周期怎么看

驱动变量：全社会用电量增速（宏观晴雨表）、发电设备利用小时数（供需松紧）、煤价（火电成本）、来水（水电）、风光装机与消纳、容量电价政策。

  • 利用小时数：低位企稳回升 → 供需改善、景气拐点；持续下行 → 过剩。
  • 煤价（秦皇岛港 Q5500）：下行 + 利用小时回升 → 火电盈利双击；暴涨 → 成本压制。
  • 来水：偏丰 → 水电大年；偏枯 → 水电承压、火电补位。
  • 新能源消纳：装机高增但弃风弃光率抬升 → 瓶颈；强配储能缓解。
  • 政策：容量电价机制 → 火电从"电量"转向"容量+调节"盈利，弱化周期波动。
当前位置（定性框架，非数据结论）：电力呈"弱周期+公用事业化"：容量电价弱化火电波动，利用小时与煤价是核心观察变量；当前火电盈利稳定性提升，水电看丰枯，新能源重消纳与电价机制落地。

产业链成本传导 · 焦煤(燃料成本) → 毛利

燃料成本占火电总成本 60–70%。煤电用煤（近似焦煤/动力煤价格 jm0）直接决定火电毛利：煤价低位→火电盈利扩张、高位→受压。

历史镜鉴：2021 煤价暴涨→火电全行业巨亏；2022–2023 后煤价回落 + 电价机制理顺→火电盈利强劲修复、分红回升。当前焦煤/动力煤约 ¥1,239/吨（2026-07），较 2021 高位明显回落，火电处盈利修复通道。

怎么读：火电看"煤价下行 + 电量稳增长 + 高分红"三重奏；水电/新能源运营商（长电/华能水电）燃料免疫、看来水与装机。分位表帮你看清各电力央企在历史便宜与否。
