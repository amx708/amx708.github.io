研究信号
周期位置
黄金处长牛通道——央行购金（去美元化）+ 实际利率下行 + 地缘避险三重驱动，矿企利润对金价高度敏感。当前金价高位运行，板块估值分化明显：多数 PE 处历史低位（分位<20%）、但 PB 普遍偏高（资源 / 成长溢价），纯粹「资源溢价」已不便宜。
景气方向
2024–25 金价中枢上移带动矿企业绩高增（紫金 / 山金 / 赤峰净利大增），产量高增的赤峰、银泰弹性最强；但 PB 多居历史中高位，安全边际要看产量兑现与克金成本，而非单纯金价。
结论信号
🟢 资源 + 低成本 + 产量增长 三角 — 优先「低 PE + 高资源储量 + 强现金流 + 低负债」的纯矿产金龙头（紫金 / 赤峰 / 山金 / 中金 / 银泰），规避「高负债 + 低质量 + 负现金流」的加工 / 困境型（恒邦 / 西部 / 荣华）。
核心催化
①央行持续购金 / 去美元化　②实际利率下行（降息周期）　③地缘避险升温　④矿企产量增产兑现　⑤资源增储 / 海外并购。
关键风险
①实际利率上行 / 美元走强压制金价　②金价高位回落　③高负债矿企财务压力　④单一矿山 / 品位下降　⑤海外地缘与汇率波动。
数据锚：10 家平均 PE 分位 ≈22% · 平均 PB 分位 ≈62% · 紫金/山金/中金/湖南黄金/银泰/赤峰/四川 PE 分位均<15% 处历史低位 · 赤峰/银泰 ROE>21% 质量顶尖 · 荣华实业已退市（数据失真）。结论为框架合成，需结合实盘研究校验。
跨层分析框架（5 层）
01
资源储量
矿山探明+控制资源储量是矿企价值的根本，储量增长靠自主勘探+并购；品位与地理位置决定长期克金成本。
02
采选冶
采矿+选矿+冶炼，克金现金成本（AISC）与回收率是核心竞争力；低成本矿（紫金/山金/银泰）抗金价波动更强。
03
产量释放
矿产金年产量及增速，新矿投产/技改扩产驱动；产量兑现决定营收弹性与规模效应。
04
金价
黄金价格由避险需求+央行购金+实际利率（美债实际收益率↓利好金价）共同决定，是矿企利润的核心变量。
05
投资逻辑
看「资源储量+低成本+产量增长」三角，金价上行放大利润；低 PE+高资源储量=安全边际，警惕高负债/单一矿山/品位下降。

产业链成本传导（市场变量传导）

黄金矿企的「成本传导」本质是金价→利润的杠杆放大：①金价（价格） → 矿企收入（量×价），是利润的核心变量，避险+央行购金+实际利率下行共驱；②采选冶成本（AISC） → 克金现金成本，低成本矿在金价下行时仍盈利；③产量 → 放大收入弹性，增产兑现增厚利润；④三者共同决定自由现金流 → 分红 / 再勘探。

护城河 = 资源储量 + 低成本 + 产量增长；低 PE + 高资源储量 = 周期底部的安全边际信号，但须警惕高负债、单一矿山与品位下降形成的「资源陷阱」。
