医药零售怎么读：核心指标框架
零售药房的「门店—集中度—处方外流」三段式 · 框架级原创整理，不复制任何付费内容
📊 数据口径：本文为框架级定性梳理，具体数值以各公司最新可得年报（2025-12-31）及公开新闻为准；估值分位见估值温度计。本页不构成投资建议。最后更新：2026-08-08
为什么医药零售不能用普通框架？
💡 一句话：药房是低毛利、高周转的零售生意，不能用高毛利消费框架——利润来自同店增长、门店扩张与统采效率，核心长逻辑是「处方外流 + 行业集中度提升」。

药房是低毛利、高周转的零售生意，不能用高毛利消费框架——利润来自同店增长、门店扩张与统采效率，核心长逻辑是「处方外流 + 行业集中度提升」。

1. 门店与同店
1.1
门店数 / 坪效 / 同店增速
四大连锁（老百姓/益丰/大参林/一心堂）靠并购 + 自建扩张；同店增速决定存量质量。
1.2
并购整合
行业从「跑马圈地」进入「整合提效」，并购后的统采与会员复用决定 ROE。
2. 处方外流与政策
2.1
双通道 / 门诊统筹
统筹药店资质稀缺且引流，处方外流加速直接利好头部；门诊统筹是近年最核心的增量逻辑。
2.2
集采与医保控费
集采品种零差价、价格透明，毛利受压但带来客流；比价系统倒逼效率。
3. 供应链与效率
3.1
统采比例 / 毛利率
统采提升毛利、数字化降低费用；龙头凭借规模与供应链优势持续挤压中小。
3.2
数字化与私域
O2O、会员私域提升复购与客单价，对冲线上比价冲击。
4. 估值锚与风险框架
4.1
估值方法
零售看低 PE/PB + 高股息 + 分红率；估值锚在「安全边际 + 现金流」，而非成长想象。
4.2
风险框架
①线上冲击 ②处方外流不及预期 ③合规/医保控费 ④并购商誉。买点常在「估值低位 + 高分红 + 整合提效」时。
实用框架：先判行业周期位置，再看商业模式与壁垒信号，最后用估值分位 + 股息率定买点。分析框架见方法论文；行业周期脉络见价格/政策周期；行业内估值冷热见估值温度计；买点回测见三轮大底回测。
